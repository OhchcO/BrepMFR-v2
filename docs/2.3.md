## 2.3 基于子图同构的机匣特征半自动标注方法

第 2.2 节定义了航空机匣的面邻接图、语义类别及实例标签。为减少重复特征逐面标注的工作量，本节采用“代表性特征选取—碎面重构—属性子图匹配—候选预标注—人工复核修正”的半自动标注流程。标注人员首先选取已经核对的特征面构建模板；对于因模型转换或建模操作而被分割的连续曲面，依据几何与拓扑条件建立面簇邻接图；随后搜索与模板结构一致的候选，并将匹配结果还原至原始面，最终由人工核查制造语义、特征边界和实例归属。谢飞等将子图同构用于制造特征识别；庄可佳等在复杂机匣螺纹孔识别中提出碎面重构与面簇子图匹配方法，为本节处理碎面和恢复原始面对应关系提供了依据。[@xie_subgraph_2018; @zhuang_threaded_casing_2026]

### 2.3.1 特征模板与属性约束

<span style="color:#C00000">【已有表：表 2-2 列出模板选取关注信息。拟补图：在同一机匣局部展示人工选取的种子面、诱导子图及模板矩阵的对应关系。】</span>

设机匣的属性面邻接图为 $G=(V,E)$，其中每个节点对应一个原始 B-rep 面，有向边对应两面的拓扑邻接。标注人员在三维模型中选取一组已核对的代表性特征面 $U\subseteq V$，按其原始面索引提取诱导子图，形成特征模板；模板也可由此前导出的 JSON 文件载入。模板所关联的语义类别由标注人员依据第 2.2.1 节的分类体系指定，子图结构本身不自动推断制造语义。原始面索引在后续面簇合并过程中予以保留，以便将匹配结果还原为逐面标签。

程序用邻接矩阵保存模板与机匣图。矩阵对角元素记录曲面类型；对于相邻面，非对角元素将共享边类型、凹凸性和环类型分别编码在百位、十位和个位；无邻接关系的位置记为 $-1$。由于边属性具有方向，匹配时须同时比较两个方向的矩阵元素。模板由所选原始面构成诱导子图，因此既限定了面类型，也限定了模板内部的连接及不连接关系，但不限定这些面在模板外侧的全部邻接结构。对于外部模板，可附加面类型、圆柱半径或面积范围等节点约束，对 VF2 搜索得到的候选进行筛选。这些约束服务于特定模板的匹配，不构成独立运行的全类别规则识别器。

模板选取需要覆盖目标特征的关键构成面，并区分目标面与相邻基体面。表 2-2 列出不同类别在模板选取和人工复核时需要关注的几何拓扑信息。这些信息用于判断候选是否具有相应制造语义，不构成一套独立于模板匹配的全类别规则识别方法。

**表 2-2 机匣特征模板选取与人工复核的关注信息**

| 类别组 | 模板选取与复核关注信息 | 需要人工区分的情形 |
| --- | --- | --- |
| 孔类（101—110） | 孔壁、孔底或肩部面的类型与邻接关系 | 通孔与盲孔、组合孔及相交孔 |
| 凸台类（201—204） | 顶面、侧面及其与基体的连接 | 基体台阶与独立凸台 |
| 型腔类（301—306） | 底面、侧壁及开口周围的面连接 | 型腔与开放槽、相交型腔 |
| 槽类（401—404） | 槽底、侧壁及沿槽向的连续结构 | 环形槽与相近的环形型腔 |
| 单面功能特征（501—503） | 目标面的几何形态及其在机匣中的位置 | 几何相近而功能不同的表面 |
| 过渡特征（601—602） | 圆角或倒角面及其邻接面 | 过渡面与主体特征的归属 |

### 2.3.2 碎面重构与面簇邻接图

<span style="color:#C00000">【拟补图：选取实际机匣中的一个碎面特征，展示原始 B-rep 面、碎面合并后的面簇邻接图及面簇到原始面索引的映射；可参考所引螺纹孔论文的重构示意，但需使用本研究模型重新制图。】</span>

同一几何曲面在 STEP 转换或局部建模过程中可能被拆分为多个相邻的 B-rep 面，使原本对应一个特征构成面的区域在邻接图中表现为多个节点。由于严格的子图同构要求模板与候选具有相同的节点结构，碎面会改变节点数量和连接方式，导致几何语义相近的特征难以直接匹配。庄可佳等在复杂机匣螺纹孔识别中提出先进行碎面重构，再开展面簇子图匹配：将属于同一连续曲面的面片聚合为代表节点，同时保留各面片的原始索引。[@zhuang_threaded_casing_2026]

碎面合并依据相邻面的几何类型与连接连续性共同判定。对于共享边的两个面，仅当其曲面类型一致，且共享边两侧的法向变化满足预设的光滑连接条件时，才将该邻接关系纳入同一面簇的扩展。沿符合条件的邻接边搜索，可得到互不重叠的面簇集合 $\mathcal{C}=\{C_1,C_2,\ldots,C_m\}$，其中每个 $C_k$ 保存组成该簇的原始面索引。采用代表节点表达一个面簇，删除簇内面片之间的连接，并将面簇与外部面之间的邻接关系继承到代表节点，形成面簇邻接图 $G_{\mathcal{C}}$。未发生碎面分裂的区域保留为单面簇。上述曲面类型和光滑连接的双重条件取自所引研究；具体连续性阈值需与模型单位和曲面精度相适应，不能仅凭曲面类型相同合并相邻面。[@zhuang_threaded_casing_2026]

模板和待标注机匣采用相同的重构准则，再在两个面簇邻接图之间比较节点及边的属性。面簇节点仍记录其所代表的曲面类型，簇间边保留由原始面簇外部连接形成的邻接属性。此时模板与目标中的同一连续曲面即使由不同数量的原始面片构成，也可以在重构后的图上比较其特征结构。面簇只是匹配阶段的辅助表示；最终语义和实例标签仍以原始 B-rep 面为单位，不以面簇编号替代原始面索引。对跨越不同特征边界或曲面连续性存疑的合并结果，应在人工复核时拆分或修正。

### 2.3.3 属性约束子图同构匹配

<span style="color:#C00000">【拟补图：面簇邻接图上的属性约束子图同构匹配流程，展示曲面类型筛选、双向边属性比较、候选去重、原始面还原及几何约束过滤；选用实际机匣中的匹配实例。】</span>

记重构后的模板图为 $T_{\mathcal{C}}$，待标注机匣图为 $G_{\mathcal{C}}$。在无碎面区域，面簇均由单个原始面构成，匹配形式退化为原始属性面邻接图上的子图匹配。对于两个图，采用 VF2 回溯搜索模板节点到机匣节点的一对一映射。候选节点首先按曲面类型筛选，并利用节点度数下限减少搜索范围；搜索过程中继续检查已映射节点之间两个方向的边属性，以及模板中不存在的内部邻接关系。只有满足模板矩阵与对应机匣子矩阵属性一致的映射，才形成候选面簇集合。

设 $A_T$ 和 $A_G$ 分别为重构后模板图和机匣图的属性邻接矩阵。对每个候选映射 $\phi:V(T_{\mathcal{C}})\rightarrow V(G_{\mathcal{C}})$，要求 $\phi$ 为单射，且满足

$$
A_T(u_i,u_j)=A_G\bigl(\phi(u_i),\phi(u_j)\bigr),\qquad \forall u_i,u_j\in V(T_{\mathcal{C}}).
$$

该条件同时约束对角位置的曲面类型、非对角位置的双向邻接属性和模板内部的非邻接关系；模板以外的机匣邻面不参与等式比较。因此，搜索得到的是与模板具有相同内部属性结构的候选面簇，不能仅凭拓扑一致性确认其制造语义。

匹配得到的代表节点通过面簇与原始面索引的映射展开，恢复候选特征包含的全部 B-rep 面，以便在三维模型中定位、着色和赋予逐面标签。这一还原步骤对下游标注尤为重要：若只保留面簇代表节点，未被选作代表节点的面片将缺少语义与实例标签。对于人工选取的种子模板，候选还可结合圆柱半径和面积范围排除大型回转主体面；采用外部模板时，可按模板文件附加的面类型、半径和面积约束进一步过滤。几何阈值应结合机匣尺寸和模型单位核查，不能视为适用于全部类别的固定判别条件。

碎面重构主要处理同一连续曲面被分割为多个面片的情形。若特征相交、共享边界或建模方式变化使真实的邻接结构发生改变，即使经过面簇合并，模板仍可能无法覆盖该区域。未匹配区域不能直接判定为非目标特征，应返回三维模型检查，视情况补充代表性模板或直接修正逐面标签。对于不同制造特征间仅因局部光滑而产生的疑似合并，也须结合设计语义和实例边界复核。

### 2.3.4 人工复核与实例编号

<span style="color:#C00000">【拟补图：同一零件的自动预标注、人工修正和最终实例着色三幅对照，明确指出误检、漏检与实例拆合的修正位置。】</span>

VF2 搜索可能因模板对称性返回多个映射，但展开到原始面后对应同一组面索引的结果只需保留一个候选。对于相互重叠的候选，先检查是否为同一特征的不同映射，避免将同一面重复赋予不同标签；已标注区域也应避免被新候选直接覆盖。候选经面簇还原后可获得模板对应的语义代码及新的实例编号，但此时仍属于有待核查的预标注结果。标注人员应结合语义着色、实例着色和原始几何检查候选、重叠区域、面簇边界及未匹配区域，修正误检、漏检和特征实例的错误拆合，最终判定以人工复核为准。

对于确认的目标面集合，标注工具分别写入语义代码 $y_i$ 与实例编号 $z_i$。同一零件上多个同类孔、槽或凸台可具有相同的 $y_i$，但应使用不同的正整数实例编号；同一实例的各成员面共享编号。圆角和倒角分别使用 601、602 语义代码，其实例编号独立于相邻主体特征。非目标面采用背景类别 000，并以 $-1$ 表示无目标实例。标注人员可在三维界面中逐面调整类别及实例编号，并用语义或实例着色检查结果。

复核后的标签按原始面顺序导出为 JSON，包含源模型文件名、面数、逐面语义数组和逐面实例数组。标注工具在导出时检查数组长度、语义代码是否属于当前类别映射、背景与实例编号是否一致，以及一个实例编号是否跨越不同语义类别；这些格式检查仍不能代替逐面语义复核。第 2.4 节进一步说明标签与图数据的对齐及数据集质量检查。当前导出文件不包含候选来源、模板版本或逐次人工修改日志，因此标注效率与修正量的定量评价须依赖另行保存的实验记录。
