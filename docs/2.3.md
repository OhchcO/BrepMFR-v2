## 2.3 基于子图同构的机匣特征半自动标注方法

第 2.2 节定义了航空机匣的面邻接图、语义类别及实例标签。为减少重复特征逐面标注的工作量，本节采用“代表性特征选取—属性子图匹配—自动预标注—人工复核修正”的半自动流程：标注人员先从模型中选取已核对的特征面作为模板，程序搜索具有相同面类型和内部邻接结构的候选区域，并对无冲突的候选预先赋予语义及实例编号；随后由标注人员核查制造语义、特征边界和遗漏区域。谢飞等已将子图同构用于制造特征识别；庄可佳等针对复杂机匣螺纹孔研究了面簇重构与子图匹配。本文标注程序直接在原始 B-rep 面邻接图上执行 VF2 匹配，未将后者的面簇重构纳入当前流程。[@xie_subgraph_2018; @zhuang_threaded_casing_2026]

### 2.3.1 特征模板与属性约束

<span style="color:#C00000">【已有表：表 2-2 列出模板选取关注信息。拟补图：在同一机匣局部展示人工选取的种子面、诱导子图及模板矩阵的对应关系。】</span>

设机匣的属性面邻接图为 $G=(V,E)$，其中每个节点对应一个原始 B-rep 面，有向边对应两面的拓扑邻接。标注人员在三维模型中选取一组已核对的代表性特征面 $U\subseteq V$，程序按其原始面索引提取诱导子图，形成待搜索的模板。模板也可由此前导出的 JSON 文件载入。模板所关联的语义类别由标注人员依据第 2.2.1 节的分类体系指定，子图结构本身不自动推断制造语义。

程序用邻接矩阵保存模板与机匣图。矩阵对角元素记录曲面类型；对于相邻面，非对角元素将共享边类型、凹凸性和环类型分别编码在百位、十位和个位；无邻接关系的位置记为 $-1$。由于边属性具有方向，匹配时须同时比较两个方向的矩阵元素。模板由所选原始面构成诱导子图，因此既限定了面类型，也限定了模板内部的连接及不连接关系，但不限定这些面在模板外侧的全部邻接结构。对于外部模板，可附加面类型、圆柱半径或面积范围等节点约束，对 VF2 搜索得到的候选进行筛选。这些约束服务于特定模板的匹配，不构成独立运行的全类别规则识别器。

模板选取需要覆盖目标特征的关键构成面，并区分目标面与相邻基体面。表 2-2 列出不同类别在模板选取和人工复核时需要关注的几何拓扑信息。这些信息用于判断候选是否具有相应制造语义，并不表示程序已为每一类别实现专门的自动识别规则。

**表 2-2 机匣特征模板选取与人工复核的关注信息**

| 类别组 | 模板选取与复核关注信息 | 需要人工区分的情形 |
| --- | --- | --- |
| 孔类（101—110） | 孔壁、孔底或肩部面的类型与邻接关系 | 通孔与盲孔、组合孔及相交孔 |
| 凸台类（201—204） | 顶面、侧面及其与基体的连接 | 基体台阶与独立凸台 |
| 型腔类（301—306） | 底面、侧壁及开口周围的面连接 | 型腔与开放槽、相交型腔 |
| 槽类（401—404） | 槽底、侧壁及沿槽向的连续结构 | 环形槽与相近的环形型腔 |
| 单面功能特征（501—503） | 目标面的几何形态及其在机匣中的位置 | 几何相近而功能不同的表面 |
| 过渡特征（601—602） | 圆角或倒角面及其邻接面 | 过渡面与主体特征的归属 |

### 2.3.2 属性约束子图同构匹配

<span style="color:#C00000">【拟补图：属性约束子图同构匹配流程，依次展示面类型筛选、双向边属性比较、候选去重及几何约束过滤；选用实际机匣的一个匹配实例。】</span>

对于模板图 $T=(U,F)$ 和待标注机匣图 $G=(V,E)$，程序利用 VF2 回溯搜索模板节点到机匣面节点的一对一映射。候选节点首先按曲面类型筛选，并利用节点度数下限减少搜索范围；搜索过程中继续检查已映射节点之间两个方向的边属性，以及模板中不存在的内部邻接关系。只有满足模板矩阵与对应机匣子矩阵属性一致的映射，才形成候选面集合。

匹配结果仍以原始 B-rep 面索引表示，便于在三维模型中定位和着色。对于人工选取的种子模板，当前程序会排除半径大于 50 mm 或面积大于 50 000 mm² 的圆柱面，以减少回转主体表面对局部特征搜索的干扰。这是当前工具的固定筛选阈值，并非由特征类别或机匣尺寸自动确定；尺寸单位与阈值适用范围需随目标模型核查。使用外部模板时，可按模板文件中的可选面类型、半径和面积约束进一步过滤结果。上述筛选均发生在 VF2 匹配流程内或其结果之后，不产生另一组独立的规则识别候选。

严格的结构匹配有明确边界。若同一制造特征因面分裂、特征相交或建模方式不同而改变了节点数量或内部邻接关系，现有模板可能无法覆盖该区域。对于没有匹配结果的区域，不能直接判定为非目标特征，应返回三维模型进行人工检查，并视情况补充代表性模板或直接修正面标签。本文不将未实现的面簇重构或近似子图匹配计入当前标注流程。

### 2.3.3 人工复核与实例编号

<span style="color:#C00000">【拟补图：同一零件的自动预标注、人工修正和最终实例着色三幅对照，明确指出误检、漏检与实例拆合的修正位置。】</span>

VF2 搜索可能因模板对称性返回多个映射，但这些映射对应同一组原始面时只需保留一个候选。程序据面索引集合去除完全重复的结果；对于相互重叠的候选，默认跳过自动赋值，以免同一面被不同候选重复占用。已标注面默认也不由新候选覆盖。其余被接受的候选会自动获得语义代码及新的实例编号，因而是有待复核的预标注结果，而非独立真值。标注人员应结合语义着色、实例着色和原始几何检查候选、重叠区域及未匹配区域，修正误检、漏检和特征边界，最终判定以人工复核为准。

对于确认的目标面集合，标注工具分别写入语义代码 $y_i$ 与实例编号 $z_i$。同一零件上多个同类孔、槽或凸台可具有相同的 $y_i$，但应使用不同的正整数实例编号；同一实例的各成员面共享编号。圆角和倒角分别使用 601、602 语义代码，其实例编号独立于相邻主体特征。非目标面采用背景类别 000，并以 $-1$ 表示无目标实例。标注人员可在三维界面中逐面调整类别及实例编号，并用语义或实例着色检查结果。

复核后的标签按原始面顺序导出为 JSON，包含源模型文件名、面数、逐面语义数组和逐面实例数组。标注工具在导出时检查数组长度、语义代码是否属于当前类别映射、背景与实例编号是否一致，以及一个实例编号是否跨越不同语义类别；这些格式检查仍不能代替逐面语义复核。第 2.4 节进一步说明标签与图数据的对齐及数据集质量检查。当前导出文件不包含候选来源、模板版本或逐次人工修改日志，因此标注效率与修正量的定量评价须依赖另行保存的实验记录。
