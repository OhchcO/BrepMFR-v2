## 2.4 机匣数据集构建

### 2.4.1 标注数据组织与质量控制

<span style="color:#C00000">【拟补图：展示原始 STEP 面、语义与实例标签及 BIN 节点的索引对应；使用新标注数据中的实际零件制作。】</span>

本文以完整父机匣为样本组织单位，通过源 STEP 文件名关联几何模型和逐面标签。标签与图节点共享原始 B-rep 面的遍历顺序，因而同名文件在重新导出或几何编辑后仍需重新核对面数与面身份。数据入库检查分为模型读取、标签格式、实例一致性和图结构四个环节；其中，标签 JSON 能够导出仅说明其满足标注工具的格式约束，不能据此认定语义和实例归属均正确。

标签文件包含源模型文件名、面数、逐面语义数组和逐面实例数组。标注工具在导出时检查数组长度、语义代码取值及同一实例的语义一致性；转换程序进一步检查整数类型、数组长度、语义代码是否属于图 2-1 的类别集合，以及语义与实例编号的对应关系。旧标签中缺少实例编号的目标面和模板未匹配的面，均须经人工复核后才能作为训练标签。

当前 JSON 格式保存最终面标签及其源文件信息，不包含候选来源、模板版本或逐次修改日志。因此，标注过程的可追溯性需由独立的版本记录承担。记录内容包括源 STEP 版本、类别表与模板版本、复核人员、误检和漏检的修正、实例拆合以及各阶段用时。最终标签数组只能反映修正后的结果，不能用于反推修正次数或人工工作量。

以编号为 001 的机匣为例，其标签文件记录的源模型为 `001.stp`，面数为 622，语义数组和实例数组均包含 622 个元素。程序检查表明，所有目标面均具有正整数实例编号，同一实例未跨越不同语义类别。进一步以未缩放的 STEP 几何核对标注界面与图提取器的面面积和质心，622 个对应位置均保持一致；图提取器执行整体归一化时，各面的面积也符合统一的尺度变换关系。这些检查为该文件的面索引对齐提供了依据，但不能代替对每个面的制造语义进行人工审查。

### 2.4.2 标签与 BIN 数据生成

<span style="color:#C00000">【拟补图：从 STEP 与人工复核标签到父图 BIN、训练子图的转换流程，标明面索引对齐和父机匣位置继承；同时示意三维柱坐标到模型周期编码的转换。】</span>

机匣转换以 STEP 模型和对应的 JSON 标签为输入，提取面、边属性及邻接关系，构建 DGL 图并保存为 BIN 文件。原始 JSON 保留图 2-1 所示三位语义代码及逐面实例编号；转换时将语义代码按固定映射转为网络需要的连续类别索引，并写入节点字段 `f`，实例编号保留在节点字段 `i`。例如，背景代码 000、柱形沉孔（通孔）代码 103 和圆角代码 601 分别映射为索引 0、3 和 28。映射表随数据集清单保存，模型预测后可将连续索引还原为论文中的语义代码。当前训练数据转换要求完整的语义与实例标签；无标签模型需使用推理专用转换流程，不能作为监督训练样本。整个转换过程以 STEP 原始面顺序作为标签数组和图节点的共同索引。

对已确定轴线、原点、轴向和周向零点的机匣，径向 $r$、角度 $\theta$ 与轴向高度 $z$ 即可确定面代表点在该坐标系中的位置。第 3.2 节模型使用的 $[\bar r,\sin\theta,\cos\theta,\bar z]$ 并非增加了第四种几何位置，而是将同一个角度展开为两个连续的周期分量。编号 001 的新转换流程将这一四维表示写入节点字段 `cylindrical_pos`，径向和轴向归一化范围由完整父零件的几何范围确定。

早期机匣转换脚本以 UV 网格中点及外部指定范围计算三维柱坐标，并将原始语义代码直接写入 `f`，因而其 BIN 不能直接供第 3 章完整模型训练。编号 001 的流程检查改用与模型输入一致的提取和转换路径：在完整父零件上计算参数曲面特征与面积质心的柱坐标位置，先生成父图，再裁剪局部子图。子图直接继承父图的节点几何和位置字段，并重新计算子图内的图距离与路径描述，避免同一面因局部裁剪而获得不同的位置编码。该单件转换验证了字段和索引的可用性；后续批量数据构建仍应对每件父机匣执行相同的面身份与数值检查。

BIN 样本的检查包括图节点数与标签数组长度、图边索引范围、实例编号与语义类别对应关系，以及连续特征中的非有限数值。逐面实例编号是关系监督的原始依据；在编号 001 的调试转换中，程序依据正整数实例编号构造面间同实例矩阵，背景面不构成正关系，并将其写入 BIN 的图级元数据。面数相等只能证明数组长度一致，不能证明图节点与原始 CAD 面身份逐一对应，因此面索引的稳定性仍需在后续每件机匣上核验。

### 2.4.3 数据集统计与划分

数据集以完整父机匣为独立样本单位。同一父机匣的局部子图、不同导出版本和标签修订版归入同一集合，避免相同结构跨训练与测试。现有划分脚本先检查完整父图的语义与实例标签，再生成父零件级清单；训练集覆盖已出现的语义类别，测试集保留完整父图，训练和验证父图才生成局部子图。划分清单保存父机匣编号和随机种子，使模型比较采用一致的数据范围。

### 2.4.4 标注质量与工作量评价

<span style="color:#C00000">【完成独立参考标注与计时记录后填写表 2-5；没有纯人工对照时，不报告相对纯人工标注的效率提升。】</span>

标注质量以独立参考标签为评价基准。参考机匣不参与特征模板选取，评价时分别比较程序预标注和人工修正后的标签。目标面覆盖率以参考标签中的目标面数为分母，计算被正确预标注的比例；预标注误标率以已预标注目标面数为分母，计算语义或实例归属错误的比例。最终标签除面级语义外，还检查同类不同实例的错误合并、同一实例的错误拆分，以及重复孔、相交特征和过渡面上的漏标与错标。

标注工作量按模板准备、候选生成、候选核查、误检删除、漏检补标和实例调整分别计时，并汇总每件机匣的总用时。若设置纯人工对照，两组采用相同零件、类别约定和完成标准，并以同一参考标签核对最终质量。当前 JSON 只保存最终标签，工作量与修正次数必须取自独立过程记录。
