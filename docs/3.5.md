# 3.5 本章小结

<span style="color:#C00000">【图表安排：本节只归纳前文证据，不新增图表；关键数值对应 3.4 节现有表格。】</span>

本章以 BrepMFR 面级分类网络为基线，分别从面内几何、完整零件结构位置和面间实例关系三个方面改进输入与注意力计算。参数曲面分支提供新的面内几何表示，柱坐标分支编码面的径向、周向和轴向位置；实例亲和分支从中间面表示预测同实例关系，并通过门控偏置作用于后部注意力层。模型在推理阶段不需要真实实例标签。

MFInstSeg 数据集上的三种子比较显示，完整配置在 1%、5%、10%、20% 和 100% 五个训练比例下的平均 mIoU 均高于原始 BrepMFR 基线和 AAGNet。其中，1% 条件下完整配置与 BrepMFR 基线的平均 mIoU 分别为 87.048% 和 83.720%，相差 3.328 个百分点。消融实验中，启用动态实例偏置相对仅采用亲和监督的配置在全部五个比例的同种子配对中均取得正向面级差值，实例分组的 Pairwise F1 与 ARI 也呈相同方向。

各组件的贡献并非在所有条件下单调增加。1% 时，参数曲面与柱坐标联合输入的平均 mIoU 低于仅采用参数曲面的配置；5% 时，完整配置比未加入实例关系模块的联合输入配置低 0.272 个百分点。因此，本章结果支持完整配置相对所列基线的比较优势及动态偏置的增量作用，但不能据此断言每项输入和辅助监督在任意数据规模下均有收益。公开合成数据上的表现也不能替代真实机匣验证；第 4 章将以父机匣级划分、完整零件推理和 UG 应用检验其工程适用范围。
