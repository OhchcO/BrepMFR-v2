# 4.1 引言

B-rep 模型以参数化曲面和拓扑连接描述零件边界。面级制造特征识别需要同时判断每个面的局部形状、它与相邻面的结构关系，以及该面在整个零件中的作用。以面为节点、邻接关系为边构建属性邻接图（AAG），能够把几何与拓扑信息纳入统一的学习框架。BrepMFR 等已有研究为这一任务提供了图表示和面级分类基础，但在本文关注的小样本条件下，输入表征和同类特征实例之间的关系仍需要进一步检验。[@zhang_brepmfr_2024]

首先，规则 UV 网格可以表达面内几何，却会受到曲面参数范围、裁剪边界和局部尺度差异的影响。若将完整零件切分为局部子图进行训练，子图内部的邻接结构还不足以说明一个面处于零件的轴向、径向或周向何处。其次，逐面语义分类只回答面属于哪一类制造特征；当同一零件上出现多个同类孔、槽或台阶时，相同的语义标签不能区分它们是否属于同一个实例。输入表征与实例关系因此分别对应两个研究问题：如何保留面内几何及完整零件位置，如何利用面间实例关系辅助语义识别。

针对上述问题，本章在原有基础面属性、边属性和 Graph Transformer 结构编码的基础上，构建参数化曲面面内表示与柱坐标位置分支，并将其融合到面节点初始特征中。完整配置以参数化曲面分支替代原始 UV 网格输入，原有 AAG 结构关系编码则继续保留。参数化曲面分支依据面面积调整采样点数、用三维最远点采样选点，再利用第一基本形式近似局部距离以建立面内邻域；柱坐标分支刻画面相对完整零件的半径、周向和轴向位置。模型进一步从中间面表示预测同实例亲和关系，经门控将动态关系偏置引入后部注意力层，同时在训练阶段以实例关系标注提供辅助监督。两部分改动分别作用于输入表征和面间关系推理，需要在实验中独立评价。

本章按照“问题分析—方法构建—实验评价”的思路展开。第 4.2 节介绍面级语义识别基线、参数化曲面编码和完整零件结构位置表示；第 4.3 节给出实例亲和关系预测、注意力偏置注入及联合训练方法；第 4.4 节在 MFInstSeg 数据集上，分别从训练样本比例、现有方法比较与组件消融三个方面评价模型。相关实验用于分析各模块的实际贡献及其适用范围，并为第 5 章面向真实大型机匣的训练与应用研究提供方法基础。
