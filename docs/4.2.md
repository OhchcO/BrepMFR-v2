# 4.2 局部训练与整图推理

真实机匣的面数和局部特征密度与公开合成零件存在差异。为使第 3 章的模型能够处理完整零件，本节给出以父机匣为数据组织单位的局部训练和整图推理方案。该方案的可用图规模、显存需求与最终识别精度，需由第 4.4 节的真实零件实验检验。

## 4.2.1 机匣图规模与显存开销

<span style="color:#C00000">【拟补表：按完整父机匣记录面数、邻接边数、实例数与完整图推理的峰值显存；实测值统一在 4.4.4 节报告，本节可引用，不预填。】</span>

设一件机匣的属性邻接图为 $G_P=(V_P,E_P)$，其中节点对应原始 B-rep 面。模型需要保存面内几何表征、邻接关系、注意力状态及实例亲和预测。当 $|V_P|$ 较大时，训练阶段的中间激活和面间关系计算会限制可用批大小；显存开销不能只由模型参数量推定。为此，数据预处理应逐件记录节点数、边数、目标实例数及各类面数，并在相同设备、精度与批大小条件下测量峰值显存。是否采用完整图训练，应依据这些记录与可用资源决定。

训练输入和评价单位也需区分。一个父机匣可以产生多个训练子图，但训练、验证、测试划分应先在父零件层面完成；由同一父机匣派生的子图只能属于同一划分。验证和测试指标应汇总完整零件的预测，避免以高度重叠的子图作为彼此独立的测试样本。

## 4.2.2 连通子图采样

<span style="color:#C00000">【拟补图：一件父机匣的完整属性图、种子面、连通扩展得到的训练子图，以及父零件级训练／验证／测试划分边界。】</span>

对于训练集中的父图，从种子面出发沿拓扑邻接关系扩展，形成不超过预设面数上限的连通节点集合 $V_S\subseteq V_P$，再提取其诱导子图 $G_S=G_P[V_S]$。种子与扩展策略应覆盖常见类别及较少出现的特征，并记录每个子图的父零件 ID、原始面索引和抽样参数。子图之间允许在训练集内部重叠，但统计样本量时应同时报告独立父零件数，不能把子图数当作机匣数。

对子图边界上的特征实例，应以完整父图的标签为准保留成员面的原实例编号。若某实例仅有部分面被采入子图，训练关系目标只在当前子图内可见的面之间构造，不把未采入的面标为负样本。对缺少有效目标面的子图，以及因面划分异常而无法保持索引对应的样本，应按统一规则剔除并记录原因。

## 4.2.3 位置继承与子图训练

<span style="color:#C00000">【拟补图：同一父机匣的两个重叠子图继承相同面索引和柱坐标位置的示意，标明位置先在父图计算、再复制到子图。】</span>

第 3.2 节的柱坐标特征以完整零件的轴线、原点、轴向正方向及周向参考方向为基准。对于每件父机匣，应先在完整模型上确定这些参照并计算所有面的径向、周向和轴向位置，然后依据原始面索引将位置向量复制到训练子图。相同父零件的同一面在不同子图中应具有相同的位置编码。若对每个子图重新估计中心或尺度，同一几何位置会获得不同数值，使训练输入与整图推理输入不一致。

模型在子图上训练时，面级语义损失只覆盖子图节点；实例亲和目标依据子图内可见的原始实例标签生成。训练日志应保存父图 ID、子图节点索引、坐标基准及类别映射，以便核查标签、位置和预测面之间的对应。模型选择仍依据未参与训练的验证父机匣，而不能从同一父零件的其他子图选取最佳检查点。

## 4.2.4 整图推理流程

<span style="color:#C00000">【拟补图：未见完整机匣从 STEP、完整图、面级语义与亲和预测到实例分组及原面索引输出的流程；若实际采用分块推理，图中补充合并步骤。】</span>

推理时对未见机匣重新构建完整属性邻接图，并以训练时相同的规则确定坐标基准、提取面属性和位置编码。模型对完整图的每个面输出语义分数，并预测候选面间的实例关系；后处理在预测语义和拓扑约束下形成特征实例。输出应保留每个预测面的原始 B-rep 索引，以供第 4.5 节的 CAD 面映射使用。

若完整图超过设备承载范围，需要采用可复现的分块推理策略，并在重叠面上合并语义分数与关系预测，再恢复完整零件的实例划分。分块结果能否等价或接近整图结果，必须由相同机匣上的对照实验验证；在该验证完成前，不将分块推理的可行性表述为已证实的性能结论。
