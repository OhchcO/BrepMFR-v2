# 4.3 预训练与机匣模型适配

机匣面级标签需要结合制造语义与实例边界人工核验，可用训练零件数可能显著少于公开合成数据。第 3 章的 MFInstSeg 实验提供了公开数据条件下的模型权重，但这些权重能否改善真实机匣识别，需要在固定机匣划分下与从零训练比较。本节说明预训练、权重迁移和机匣子图微调的实验方案。

## 4.3.1 公开数据预训练

<span style="color:#C00000">【图表安排：公开数据到机匣的迁移路径可与 4.3.2 节权重适配图合并；四种核心对照条件统一列在 4.4.3 节实验表中。】</span>

公开数据预训练沿用第 3 章的图构建、几何编码与实例关系目标，在 MFInstSeg 训练集上学习模型参数，并仅使用其验证集选择检查点。预训练阶段不读取目标机匣测试集的标签，也不以真实机匣测试指标反复选择公开数据检查点。应记录所用公开数据比例、类别映射、随机种子、训练步数及检查点标识，使后续迁移实验能够复现。

预训练与从零训练的作用应分别对 BrepMFR 基线和完整方法检验。四个核心条件为：基线从零训练、基线公开数据预训练后适配、完整方法从零训练，以及完整方法公开数据预训练后适配。这样的配对设计既能观察同一结构中的预训练增量，也能在相同初始化路径下比较结构增量。AAGNet 可在相同机匣划分上作为从零训练的现有方法对照。

## 4.3.2 权重迁移与类别适配

<span style="color:#C00000">【拟补图：公开数据检查点的编码层、实例分支与机匣分类头之间的加载和重初始化关系。拟补表：逐模块记录权重是否成功加载、输入维度及机匣类别映射，以实际适配日志为准。】</span>

MFInstSeg 与机匣数据集的语义类别定义不同，不能直接沿用公开数据分类头的输出维度和类别顺序。迁移时先核对图节点、边属性与几何输入的维度和含义，再加载维度兼容的编码层权重；机匣语义分类头应按第 2.2 节的类别表重新建立。实例亲和分支能否复用，取决于两套数据的实例标签约定及输入结构是否一致，不能仅凭参数形状相同认定其目标相同。

权重加载应逐层记录成功迁移、重新初始化和未加载的参数。若为适配机匣轴线与位置范围而改变柱坐标定义，还应明确该变更影响的模块，并在四个核心条件中保持相同的机匣输入协议。比较结果时，预训练条件与从零训练条件除初始化来源外，应尽量共享网络结构、数据划分、损失定义和模型选择方式。

## 4.3.3 机匣子图微调

<span style="color:#C00000">【拟补图：从零训练与预训练微调在相同父机匣划分下的验证指标随训练轮次变化曲线；须由真实运行日志绘制。】</span>

目标域训练以第 4.2 节构建的机匣连通子图为输入。每个训练子图继承完整父零件的位置特征与人工复核标签；验证集和测试集按独立父机匣划分。为控制预训练实验中的额外训练预算，四个核心条件应使用一致的目标域训练轮次或优化步数、批大小、学习率选择范围与早停依据，并分别记录收敛曲线和最佳检查点。

目标域评价应先报告逐机匣指标，再汇总不同零件的均值与波动。若预训练提升仅集中于某一类别或某一规模的零件，应结合类别频数与实例数解释，而不将总体差值直接归因于普遍的迁移效果。现有公开数据结果不能替代这些目标域对照；其有效性以第 4.4 节的实测结果为准。
