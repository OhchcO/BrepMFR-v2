# 4.4 真实机匣识别实验

本节规定真实机匣实验的数据划分、对照条件和评价方式。现有公开数据实验不能代替未见机匣的性能测量；在机匣标签、训练记录和逐件测试结果齐备前，本节不报告真实机匣的识别精度或预训练增益。

## 4.4.1 数据划分与评价指标

<span style="color:#C00000">【图表安排：父机匣、面、实例及类别分布统计表应放在 2.4.3 节，本节引用该表并说明测试类别覆盖；无需再复制一张内容相同的数据集表。】</span>

数据集统计以完整父机匣为单位，分别给出零件数、B-rep 面数、邻接边数、目标特征实例数，以及各语义类别的零件覆盖数和面数。每件零件应保留原始 STEP、人工复核后的逐面语义与实例标签、固定面索引、坐标参照和数据转换状态。训练、验证、测试零件互不重叠；同一父零件衍生的任何子图均不得跨划分。若数据来源包含同一设计的不同版本，还应检查其几何近似和设计关联，防止近重复零件造成信息泄漏。

语义识别报告逐面准确率、Macro-F1 与 mIoU，并在每个类别上给出 IoU 或 F1。实例评价报告原始面间关系 Pairwise F1、分组后 Pairwise F1 和 ARI；背景面与无效实例的处理规则应与第 3.4 节一致。除了在全部测试面上汇总混淆矩阵，还应逐件报告指标，再给出零件层面的均值与离散程度。这样既能反映总体识别能力，也能避免面数较大的单件机匣完全支配结论。任何未出现在测试集中的类别应明确列出，不纳入该类别的指标均值。

## 4.4.2 与现有方法的性能比较

<span style="color:#C00000">【拟补表：在相同父机匣测试集上列 AAGNet、BrepMFR 与本文方法的逐种子 mIoU、Macro-F1、实例指标及均值±标准差；缺少可比实例输出的方法单独注明评价口径。】</span>

方法比较包括 AAGNet、原始 BrepMFR 和本文完整方法。三者使用同一父机匣划分、相同的语义类别定义、人工核验真值和测试程序，分别保留各自所需的输入表示。应在每个随机种子下配对训练和评价，报告逐件、逐种子结果及均值和标准差。模型选择仅依据验证父机匣，不使用测试集调整超参数或实例分组阈值。

比较的主要对象是面级语义与实例划分性能。若某方法没有输出与本文一致的实例关系结果，应说明其输出与后处理口径，而不能把语义 mIoU 当作实例识别性能。公开数据集上的第 3 章结论只能提供方法有效性的前期证据；真实机匣上的方法排序应由本节的同协议结果独立确定。

## 4.4.3 预训练与从零训练对比

<span style="color:#C00000">【拟补表：BrepMFR 与本文方法各自从零训练／公开数据预训练的 2×2 配对结果，列目标域训练预算、逐种子语义与实例指标及配对差值。】</span>

按照第 4.3 节的四个核心条件，分别比较 BrepMFR 和本文方法在从零训练、公开数据预训练后的机匣表现。对于同一结构，预训练条件减去从零训练条件的指标差值反映该初始化路径的影响；对于同一初始化路径，本文方法减去 BrepMFR 的差值反映结构配置的综合影响。四组实验应共享目标域划分、评估程序和训练预算，并记录实际加载的权重层及分类头初始化方式。

若机匣样本量允许，可进一步按目标域训练零件数设置若干比例，以判断预训练作用是否随标注量变化。跨比例实验需保留固定测试父机匣，并说明训练子集是否嵌套。预训练增益可能因类别与几何分布差异而变化，故须同时观察各类别、实例指标及未见零件的错误案例。

## 4.4.4 训练与推理开销

<span style="color:#C00000">【拟补表：逐方法、逐机匣列参数量、训练时间、峰值显存、图构建、网络推理、实例后处理及 NX 映射显示时间；首次转换与缓存命中分别统计。】</span>

资源评价在固定硬件、软件环境及数据输入下记录模型参数量、单轮和总训练时间、峰值显存、完整机匣图构建时间、模型推理时间和实例后处理时间。CAD 插件的 STEP 定位、跨内核面映射与着色耗时应另行报告，以免把系统前后处理时间归入神经网络推理。首次转换和有效缓存命中也应分开计时。

对于无法直接在设备上完成整图推理的零件，应记录失败面数阈值、内存或显存错误，以及所用分块策略和合并规则。资源结果应与逐件面数和实例数一起呈现，使运行开销能够对应到具体零件规模。

## 4.4.5 典型零件与错误分析

<span style="color:#C00000">【拟补图：未见机匣的原模型、人工真值、语义预测和实例着色对照，分别标注语义误分、实例误合并／拆分及面映射失败；至少包含表现不同的独立零件。】</span>

案例分析应选取未参与训练与调参的完整机匣，展示原始零件、人工标签、语义预测与实例划分，并在图中标注具体面或实例的错误位置。需要区分语义误分类、同类不同实例误合并、单一实例误拆分、背景面误识别和 CAD 面映射失败。对于自动标注阶段存在争议的面，还应回查人工复核记录，避免把标签不确定性全部归因于模型。

典型案例须与总体评价对应：选择高、中、低表现零件，并说明其面数、类别覆盖和特征密度，而非只展示成功样例。真实机匣的定量表格和图像应在原始测试及 NX 运行记录完成后填入，不能根据 MFInstSeg 或 41 面公开样例推算。
