# 4.5 本章小结

本章围绕 B-rep 零件的面级制造特征识别任务，针对面内几何采样难以兼顾不同曲面尺度、局部子图缺少完整零件位置参照，以及逐面分类难以利用同类特征实例关系的问题，提出了结构位置编码与动态实例亲和偏置相结合的改进方法。该方法沿用 BrepMFR 的基础面属性与 AAG 结构关系编码，分别从输入表征和面间关系建模两个层面增强图 Transformer 的特征表达。

在输入表征方面，采用面积自适应采样与三维最远点选样构建参数化曲面特征，并利用第一基本形式确定采样点的局部邻域；同时，以完整零件为参照构造柱坐标位置特征，保留面的径向、周向和轴向信息。完整模型以该曲面分支替代原始 UV 网格输入，再通过门控机制融合基础面属性与新增特征。从模型设计上看，这一组合有助于同时表达局部曲面形状和零件整体结构位置，预期能够改善训练样本较少时的面级语义识别。

在实例关系建模方面，利用中间层面特征预测同实例亲和概率，以实例关系损失提供辅助监督，并将预测关系作为后部注意力层的动态偏置。该设计使面间同实例信息参与语义特征更新，而推理阶段无需真实实例标签。理论上，亲和监督有助于区分同类不同实例的面，动态偏置则使预测到的关系进一步作用于图编码过程；两者的实际贡献应由逐项消融结果判定。

本章在 MFInstSeg 数据集上设置了不同训练比例的方法比较与组件消融实验。已完成的 1% 和 5% 单种子实验中，完整方法相对原始 BrepMFR 基线的 mIoU 均有所提高，初步支持本章的改进方向。对于输入分支、亲和监督和动态偏置能否在不同数据规模下持续产生正向作用，仍需结合后续训练比例、重复种子及同协议方法比较进行检验。第 5 章将在真实大型机匣数据上研究完整零件位置继承、局部子图训练与 CAD 系统中的识别结果映射，进一步考察本章方法的应用效果。
