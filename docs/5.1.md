# 5.1 研究工作总结

本文以航空机匣制造特征的面级语义识别与实例区分为研究对象，围绕真实零件标签获取、B-rep 几何与拓扑信息表达、小样本条件下的实例关系建模，以及识别结果在 CAD 系统中的定位与展示，构建了由机匣标注、图数据转换、模型训练到 NX 结果映射的技术流程。研究工作分别从数据准备、识别方法和工程应用三个层面展开。其中，公开数据集上的识别实验已有三个随机种子的结果；真实机匣数据集的统计、模型泛化性能及系统应用指标仍需依据独立零件的运行记录补充。

在数据准备方面，本文以原始 B-rep 面作为标注和图节点的共同单位，制定包含背景面、孔、凸台、型腔、槽、功能面及过渡特征的初始语义分类规范，并分别定义面级语义代码和特征实例编号。针对同类局部特征在机匣上重复出现的情况，标注工具从人工选取的代表性面提取属性子图模板，通过属性约束子图同构搜索相似区域，对无冲突候选进行预标注，再由人工核查制造语义、特征边界和实例归属。复核标签按原始面顺序导出，并与 STEP 模型生成的属性图对应。当前流程能够提供数据构建方法，但预标注覆盖率、最终标签质量和人工工作量尚须在真实机匣上依据独立参考标注进行评价。

在识别方法方面，本文以 BrepMFR 面级分类网络为基线，研究面内参数曲面编码、相对于完整零件的柱坐标位置编码，以及动态实例亲和注意力偏置。前两者补充面内部连续几何和零件内结构位置；实例关系分支从中间面表示预测同实例概率，以辅助损失训练关系预测器，并将预测关系经门控偏置反馈至后部注意力层。推理阶段的关系输入由模型预测获得，不使用真实实例标签。

MFInstSeg 公开数据集的三个随机种子实验表明，在 1%、5%、10%、20% 和 100% 训练比例下，完整方法相对原始 uv_aag 基线的平均 mIoU 分别提高 3.328、0.456、1.219、0.707 和 0.248 个百分点；相对 AAGNet 的面级 mIoU 均值也均为正。其中，1% 训练比例下完整方法与 uv_aag 基线的平均 mIoU 分别为 87.048% 和 83.720%。在相同几何输入和亲和监督下，开启动态偏置相对关闭偏置的配置，在五个比例的全部 15 次同种子配对中提高了面级 mIoU；实例分组后的 Pairwise F1 和 ARI 也在这些配对中提高。上述结果支持完整配置在当前公开数据面级评价中的比较优势及动态偏置的增量作用。

各分支的作用仍有边界。1% 训练比例下，参数曲面与柱坐标联合输入的平均 mIoU 低于单独采用参数曲面的配置；5% 时，完整配置的平均 mIoU 比未加入实例关系模块的联合输入配置低 0.272 个百分点。因此，现有证据不能说明每一输入分支或辅助监督在所有数据规模下均带来正向收益。公开合成零件上的比较结果，也不能直接代替真实机匣上的语义、实例和资源评价。

在工程应用方面，本文建立了 NX 2212 插件与独立 Python 推理程序之间的输入和结果接口。插件通过几何与拓扑签名、全局一一指派及邻接复核，将识别程序的面索引对应到 NX 面对象，并在映射校验后执行实例着色与交互浏览。现有一个 41 面公开数据 STEP 样例的 Python 结果文件记录了成功输出和 9 个预测实例，可用于检查输出协议；它不能证明真实机匣上的识别精度，也不能单独证明 NX 界面中的映射与显示效果。上述工程效果仍需由真实机匣的人工标签、NX 现场图像和运行日志分别核验。
