# 5.3 研究不足与未来展望

现有公开数据实验覆盖五种训练比例和三个随机种子，但部分汇总结果缺少可同时核对的数据划分清单、检查点、原始测试日志与 AAGNet 复现版本。后续应按“划分—种子—配置—检查点—指标”的对应关系归档材料，补充统一条件下的模型规模、峰值显存与训练、推理耗时。对于 1% 时联合输入低于单独曲面输入、5% 时完整方法低于无实例模块联合输入的现象，还应结合逐类样本量、混淆矩阵和同类不同实例的错误案例分析原因，而不以总体均值代替机制解释。

机匣数据集的类别覆盖和标注质量仍需实测。初始分类规范包含 30 个二级语义类别，但真实样本未必覆盖全部类别；功能面、组合孔和过渡特征的边界也可能需要依据设计资料复核。后续应逐件保存原始 STEP、人工复核标签、模板来源和修正记录，在独立参考标注上比较预标注与最终标签的覆盖率、错误类型及人工工作量。数据划分应以完整父机匣为单位，并记录同系列零件及不同导出版本，防止高度相似的局部子图跨训练与测试集合出现。

真实机匣的模型适配尚未形成可报告的对照结果。现有机匣转换程序已记录径向、角度和轴向高度三个位置量；与第 3 章完整模型衔接时，还需统一面代表点、归一化范围、角度的周期编码及参数曲面输入。完成逐面特征对齐后，应在相同父机匣划分和训练预算下，分别比较 BrepMFR 与本文方法的从零训练和公开数据预训练条件，并在未见完整机匣上同时报告面级语义、实例分组和资源指标。只有这些结果齐备，才能判断公开数据上的方法优势能否迁移到目标场景。

NX 应用的适用范围目前限于可追溯到原始 STEP 的未编辑单实体，跨内核面映射要求完整且无歧义。后续应在多件独立机匣上保存同次运行的映射日志、着色与高亮图像、异常回滚记录和各阶段耗时，以分别评价模型识别质量与系统显示可靠性。对于经过 NX 编辑的零件、多实体或装配体，以及几何与拓扑都难以区分的对称面，还需研究可追溯的面身份更新和歧义处理方法。
