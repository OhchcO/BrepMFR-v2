# SPE-PCAAG 10D Geometry Finalization Plan

> **For Codex:** Execute this plan with test-driven development. Do not run
> full-dataset conversion or training; only targeted unit tests and one-sample
> smoke checks are allowed.

**Goal:** Finalize a stable geometry representation for the thesis: topology
only, UV-AAG, 10D point-cloud AAG, cylindrical AAG, and 10D point-cloud plus
cylindrical SPE-PCAAG.

**Architecture:** Keep the original BRepMFR semantic model and the already
implemented instance-bias branch unchanged. Extend each adaptively sampled
surface point from XYZ plus normal to
`[x,y,z,nx,ny,nz,u,v,H*L,K*L^2]`, where `u,v` are normalized face parameters
and `L` is the sampled full-part bounding-box diagonal. Encode the 10D points
with the existing lightweight masked PointNet path. Use explicit experiment
aliases so every ablation differs by one information source.

**Tech Stack:** Python, NumPy, PyTorch, DGL/PyG, pythonocc-core, occwl, pytest,
PowerShell.
