# Environment Smoke-Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only command that proves a prepared MFRInstSeg BIN can pass through the project's real dataset, collator, model, and selected CPU/CUDA device.

**Architecture:** Keep reusable, dependency-light validation helpers in `envtest.py`, then lazily import PyTorch/DGL/project modules inside the real smoke-test stages so missing packages produce useful failures. Reuse `CADSynth`, `collator`, `resolve_experiment_alias`, and `BrepSeg`; configure a small model while preserving the exact input switches of the selected experiment.

**Tech Stack:** Python 3.8, argparse, pathlib, PyTorch, DGL, PyTorch Lightning, pytest

## Global Constraints

- Do not train, convert data, modify manifests, or write checkpoints.
- Default to `baseline`; support every alias accepted by `resolve_experiment_alias`.
- For `pc_aag`, validate the formal parameter-surface profile: intrinsic neighbours, untrimmed input, and gated fusion.
- Return exit code `0` only after a finite, correctly shaped real forward output.
- Import optional environment dependencies lazily so failures are reported rather than raised at module import time.
- Preserve all existing project behavior.
