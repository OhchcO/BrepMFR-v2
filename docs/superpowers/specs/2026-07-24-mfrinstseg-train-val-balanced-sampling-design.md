# MFRInstSeg 训练集与验证集均衡抽样设计

## 目标

修改 `tools/sample_mfrinstseg_1pct.py`，让它同时从 MFRInstSeg 官方训练集和验证集中抽取固定比例的小样本，并保证两个子集各自的 0～23 类加工特征实例数量尽量一致。

## 配置

- `--ratio`：同时控制训练集和验证集的抽样比例，默认值为 `0.01`。
- `--seed`：随机种子，默认固定为 `2026`；相同数据、比例和种子必须得到相同结果。
- `--classes`：参与均衡的类别，默认值为 `0-23`；类别 24 不参与均衡，但对应面仍保留在选中的模型中。
- `--swap-attempts`：贪心选择后的交换优化次数，沿用现有配置。

## 数据流程

1. 分别读取官方 `train.txt` 和 `val.txt`，只对划分内的唯一模型进行抽样。
2. 从各自模型的 `labels/*.json` 中读取 `seg` 和 `inst`。
3. 根据实例邻接矩阵的连通分量统计每个模型内各语义类别的特征实例数。
4. 训练集与验证集独立执行现有的多标签贪心选择和交换优化。
5. 两个划分都使用同一个固定随机种子，且互不混合候选模型。

## 输出

输出目录中生成：

- `train.txt`：均衡训练子集模型编号。
- `val.txt`：均衡验证子集模型编号。
- `train_class_statistics.csv`：训练子集与随机训练子集的类别统计。
- `val_class_statistics.csv`：验证子集与随机验证子集的类别统计。
- `selection_report.json`：比例、随机种子、两个划分的数量、均衡目标值和逐类实例数。

原始 `train.txt`、`val.txt`、`test.txt` 和标签文件不修改。测试集不抽样。

## 错误处理

- 比例不在 `(0, 1]` 时终止并报告错误。
- 划分清单或标签缺失、标签结构不合法时终止，避免生成不完整清单。
- 某个参与均衡的类别在对应官方划分中完全不存在时终止并列出类别编号。

## 验证

- 使用小型合成标签数据验证训练集和验证集均会生成清单。
- 验证两个清单的模型数量分别等于各自唯一模型数乘比例后向下取整，且至少为 1。
- 验证相同种子重复运行得到相同清单。
- 在完整 MFRInstSeg 上运行，确认输出 ID 均属于各自官方划分，并比较均衡抽样与普通随机抽样的类别极差和变异系数。
