# 表示消融与实例评测设计

## 目标

本期只完成两个可独立验证的能力：

1. 将面 UV 网格编码做成显式开关，使 Topo-AAG、UV-AAG、PC-AAG、
   UV+PC-AAG 能在同一训练入口中公平比较。
2. 在测试集评测中导出动态亲和预测，并给出实例分组指标，使网络最终输出
   能从“逐面语义类别”扩展为“特征实例包含哪些面”。

本期不修改动态实例偏置的注入层数、门控方式或计算公式。晚层门控动态偏置
作为下一期独立改动，避免同时改变输入表示、注意力机制和评价指标。

## 表示开关

模型继续保留原有 UV BIN 字段，`use_face_uv=False` 时只是不消费该字段，
因此共享 BIN 缓存无需重建。

四个正式消融别名：

| 别名 | UV 面网格 | 面点云 | 柱坐标 | 用途 |
|---|---:|---:|---:|---|
| `topo_aag` | 否 | 否 | 否 | 仅 AAG 拓扑及原有标量/类别属性 |
| `uv_aag` | 是 | 否 | 否 | 显式 UV 基线，等价于原 `baseline` |
| `pc_aag` | 否 | 是 | 否 | 纯 PC-AAG |
| `uv_pc_aag` | 是 | 是 | 否 | UV 与点云联合，等价于原 `point` |

旧别名保持含义不变，以保证已有实验和 checkpoint 可复现：

- `baseline` 仍启用 UV；
- `point` 仍表示 UV + 点云；
- `cyl`、`cyl_affinity`、`spe_pcaag`、`full` 仍启用 UV。

关闭 UV 后，UV 编码所占的半个隐藏维度由零向量替代，其余面面积、曲面类型、
环数和度数编码维度不变。这样 Transformer 输入宽度、分类器结构和训练设置
保持一致，消融差异仅来自输入表示。

## 实例评测

### 推理与标签使用边界

- `oracle`：GT 实例矩阵输入模型，是理论上界。
- `dynamic` / `dynamic_affinity`：模型只根据输入几何和拓扑预测亲和矩阵；
  GT 实例矩阵只在测试脚本中计算指标，不参与前向推理。
- `baseline`：没有可预测的亲和 logits，只输出语义指标。

测试入口增加可选实例评测开关。开启后数据集要求测试 BIN 含实例矩阵，但该
要求不改变动态模型的推理输入逻辑。

### 亲和指标

对每个图的有效面取上三角非对角面，在排除背景语义类后，以
`sigmoid(logit) >= threshold` 判断同实例关系，累计：

- Pairwise Precision
- Pairwise Recall
- Pairwise F1

默认阈值为 0.5，可由命令行修改。

### 后处理聚类

每个面先作为独立集合。只有同时满足以下条件的一对面才合并：

1. 两面在 AAG 中直接相邻；
2. 两面的预测语义类别相同；
3. 两面均不是背景类；
4. 预测亲和概率不低于阈值。

使用并查集得到每个样本的实例编号，输出每个实例的语义类别与面索引集合。
测试结果同时记录：

- 聚类后的 Pairwise Precision / Recall / F1；
- Adjusted Rand Index（ARI）；
- 预测实例数、GT 实例数及实例数量 MAE。

GT 实例划分遵循数据预处理脚本的既有定义：在同一语义类别内，将实例矩阵
视为无向图并取连通分量；孤立特征面算作单面实例；默认排除语义类 24。

## 输出

语义指标继续写入原有 `test_metrics.json` 和 `test_log.txt`。开启实例评测时，
追加 `instance_evaluation` 字段，并为每个样本生成
`predicted_instances.json`，内容包含样本 ID、实例 ID、语义类别和面索引。

旧 checkpoint 若没有 `use_face_uv` 超参数，评测时默认视为 `True`，保证向后
兼容。
