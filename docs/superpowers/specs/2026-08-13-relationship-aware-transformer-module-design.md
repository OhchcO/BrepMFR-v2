# 图一关系感知图变换器模块改版设计

## 目标

修改 `docs/img/overall_algorithm_framework.svg` 的第四列，使图一准确表达以下推理顺序：前层图变换器先提取中间面特征，IAAB 再预测实例关系偏置，最后两层利用该偏置增强注意力计算，随后完成面级加工特征预测。

本轮只调整图一的关系感知推理部分及其通向任务输出的连线，不修改图二、图三和其他文件。

## 模块结构

第四列使用一个统一的外层框，标题为“关系感知图变换器”。外层框内部采用纵向三模块布局：

1. **前层基础编码**
   - 输入图序列 `X⁰` 和固定结构偏置 `B_AAG`；
   - 学习语义与拓扑上下文；
   - 输出中间面特征 `H_mid`。

2. **IAAB 实例关系预测**
   - 使用紫色并标注“创新点 2”；
   - 从 `H_mid` 预测面—面亲和关系；
   - 生成动态实例关系偏置 `B_inst`。

3. **后两层偏置增强**
   - 使用橙色表示动态偏置注入；
   - 简洁展示组合偏置 `B_AAG + B_inst`；
   - 在最后两层执行关系感知注意力计算；
   - 输出最终面特征 `H⁸` 和图级表示 `g⁸`。

三个模块使用垂直正交箭头连接，明确顺序为：

`前层基础编码 → IAAB 实例关系预测 → 后两层偏置增强 → 面级加工特征预测`

## 信息边界

图一不展示亲和矩阵内部结构、双路径注意力公式、门控标量、正负样本划分和具体前层数量。第四列底部保留“IAAB 与后层注入细节见图三”。

为避免误解，图中必须明确 IAAB 是中间关系预测模块，而不是最终任务预测头；`B_inst` 进入后两层注意力偏置，而不是直接加到最终特征上。
