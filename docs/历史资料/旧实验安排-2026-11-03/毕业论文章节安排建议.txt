航空机匣制造特征识别毕业论文章节安排建议
整理日期：2026年7月24日

一、总体定位

论文建议围绕“数据构建—识别方法—工程应用”形成一条完整主线：

1. 真实航空机匣模型数量少，逐面语义标签和实例标签获取困难，因此研究自动标注及数据集构建方法。
2. 小样本条件下，仅依靠语义监督容易出现同类不同实例混淆，因此研究SPE-PCAAG和动态实例亲和注意力偏置。
3. 单个真实机匣包含上千个面，完整图训练容易出现显存溢出，因此研究局部子图训练、完整机匣推理，并将识别模型集成到UG中。

三项核心研究内容分别解决“数据从哪里来”“模型如何识别”“方法如何落地”三个问题，形成从原始机匣模型到制造特征识别结果的闭环。

建议论文题目可围绕以下方向拟定：

《面向小样本大型航空机匣的制造特征智能识别方法与系统研究》

也可根据学校命名习惯调整为：

《基于结构位置编码与实例关系引导的航空机匣制造特征识别研究》

三、第1章 绪论

1.1 研究背景与意义

说明航空机匣制造特征识别在工艺规划、加工信息提取和智能制造中的作用，并指出真实机匣具有模型数量少、单模型规模大、标注成本高等特点。

1.2 国内外研究现状

建议从以下方面组织：

（1）基于规则和图匹配的制造特征识别；
（2）基于B-rep图神经网络的制造特征识别；
（3）B-rep Transformer及注意力机制；
（4）制造特征语义分割与实例分组；
（5）工业CAD数据集构建与自动标注；
（6）CAD/UG环境下的智能识别系统。

1.3 当前研究存在的问题

（1）真实航空机匣缺少大规模、高质量的逐面语义与实例标注；
（2）小样本条件下，网络难以充分学习制造特征结构；
（3）同一语义类别下的不同制造特征实例容易发生混淆；
（4）大型机匣完整图训练计算量大，容易显存溢出；
（5）已有算法与实际CAD软件之间缺少完整应用闭环。

对应第3章、第4章和第5章分别介绍三项工作。

五、第3章 基于几何拓扑规则与子图同构的航空机匣制造特征自动标注及数据集构建

本章定位：

第3章不是单纯介绍Qt界面，而是提出一套“自动识别—交互修正—数据导出”的航空机匣标注方法。Qt只是该方法的轻量化实现载体。

建议章节名称：

《基于几何拓扑规则与子图同构的航空机匣制造特征自动标注及数据集构建》

3.1 航空机匣制造特征标注问题定义

（1）制造特征类别体系；
（2）逐面语义标签定义；
（3）同类不同实例的实例ID定义；
（4）背景面、过渡面和复合特征处理规则；
（5）标签文件与BIN文件格式。

3.2 航空机匣B-rep图构建与特征描述

（1）原始模型读取；
（2）面、边、环及邻接关系提取；
（3）曲面类型、面积、半径、方向等几何属性提取；
（4）凹凸边、边界关系和局部拓扑结构描述；
（5）特征矩阵构建。

3.3 基于几何拓扑规则的自动标注

介绍不同制造特征对应的几何条件和拓扑条件，根据规则搜索候选面集合并赋予语义标签及实例ID。

本节应重点说明：

（1）规则的输入属性；
（2）候选面筛选；
（3）面集合扩展；
（4）特征边界确定；
（5）同类实例拆分；
（6）规则冲突处理。

3.4 基于特征矩阵与子图同构的自动标注

将已知制造特征表示为模板子图，将机匣表示为待搜索图，在节点属性和边属性约束下进行子图匹配。

建议描述：

模板图 G_T=(V_T,E_T,X_T)
机匣图 G_C=(V_C,E_C,X_C)

通过映射关系φ将模板节点映射至机匣节点，同时保持邻接结构和几何属性的一致性。

本节应介绍：

（1）模板特征矩阵；
（2）候选节点过滤；
（3）属性约束子图同构；
（4）匹配阈值；
（5）多重匹配；
（6）匹配冲突消解；
（7）实例ID生成。

3.5 多策略融合与人工交互修正

建议形成以下标注流程：

几何拓扑规则识别
→ 子图同构补充或验证
→ 冲突检测与置信度判断
→ 人工检查和少量修正
→ 输出最终标签

人工修正是质量控制环节，不影响方法被称为“自动标注方法”。但论文必须分别报告修正前的自动标注能力和修正后的最终数据质量。

3.6 Qt标注系统与BIN数据自动生成

（1）Qt系统架构；
（2）模型显示与面选择；
（3）自动标注结果可视化；
（4）错误标签修改；
（5）语义标签和实例标签保存；
（6）B-rep图节点、边及属性生成；
（7）SPE所需全局空间信息写入；
（8）BIN文件生成与一致性检查。

界面截图可以作为实现说明，但不能成为本章主体。主体应是标注算法、数据组织和实验验证。

3.7 自动标注实验与Aero-Casing数据集统计

建议比较：

（1）纯人工标注；
（2）仅使用几何拓扑规则；
（3）仅使用子图同构；
（4）几何拓扑规则与子图同构融合；
（5）融合方法加人工修正后的最终结果。

建议报告：

（1）面级Accuracy、Precision、Recall、Macro-F1；
（2）各制造特征类别的标注准确率；
（3）自动标注覆盖率；
（4）错误标注面数和漏标面数；
（5）人工修正面数及修正率；
（6）错误实例拆分、错误实例合并和漏检实例数量；
（7）自动处理时间；
（8）人工检查与修正时间；
（9）相比纯人工标注的时间节省比例；
（10）Aero-Casing中模型数、面数、类别数和实例数统计。

当前尚未保存自动标注修正率，可采用回溯方式补测：

（1）冻结当前工具版本、规则和模板；
（2）选择3至5个具有代表性的机匣，优先选择未参与规则和模板设计的新机匣；
（3）重新运行自动标注并保存修正前标签；
（4）人工完整检查，得到最终参考标签；
（5）比较修正前和修正后标签；
（6）记录自动处理时间和人工修正时间。

建议至少保留以下文件：

casing_01_auto.json
casing_01_final.json
casing_01_corrections.json

注意：不能使用自动生成标签同时作为自动标注算法的真值。最终参考标签必须经过完整人工复核。

本章预期结论：

几何拓扑规则和属性约束子图同构具有互补性，可以自动完成大部分航空机匣制造特征标注；经少量人工校正后，能够高效生成可靠的逐面语义标签、实例标签和B-rep图数据。


六、第4章 基于SPE-PCAAG与动态实例亲和偏置的小样本制造特征识别方法

本章定位：

第4章是论文的核心算法章节，重点证明实例关系监督能够在低数据条件下指导语义分割，并且推理阶段不需要真实实例标签。

建议章节名称：

《基于SPE-PCAAG与动态实例亲和偏置的小样本制造特征识别方法》

4.1 问题描述与基线网络

（1）BrepMFR基线网络；
（2）低数据条件下语义特征学习不足；
（3）同一语义类别下不同实例容易混淆；
（4）现有注意力缺少实例级结构约束。

4.2 改进网络总体结构

给出完整网络结构图，说明：

（1）B-rep几何与拓扑编码；
（2）SPE-PCAAG位置编码；
（3）Transformer特征提取；
（4）实例嵌入与动态亲和偏置；
（5）语义分类头；
（6）训练期损失和推理期数据流。

4.3 SPE-PCAAG结构位置编码

重点说明：

（1）大型机匣局部裁剪后会丢失全局位置；
（2）在完整机匣上统一计算柱坐标；
（3）局部子图继承其节点在完整机匣中的全局柱坐标；
（4）柱坐标使网络知道局部区域位于机匣的轴向、径向和周向位置；
（5）角度可使用sinθ和cosθ表示，降低角度周期不连续问题；
（6）SPE能够提供全局空间锚点，但不能恢复裁剪区域之外未输入的几何结构。

4.4 动态实例亲和注意力偏置

网络中间层根据节点特征产生实例嵌入，并预测面与面之间的同实例概率：

P_ij = sigmoid((e_i·e_j-δ)/τ)

再生成动态实例偏置：

B_inst,ij = g(2P_ij-1)

注意力计算中同时结合拓扑偏置、位置偏置和动态实例偏置。

实例标签只用于训练损失，不作为模型输入。推理时由网络根据几何、拓扑、SPE及中间特征自行计算实例亲和关系。

4.5 实例亲和损失与困难负样本

训练时利用真实实例标签生成面关系目标：

同一实例的面为正样本；
不同实例的面为负样本；
同一语义类别、拓扑距离较近但属于不同实例的面为困难负样本。

总损失可写为：

L_total = L_semantic + λ_inst L_affinity

动态实例偏置建议限制在局部K-hop范围内，以减少完整图推理时未经训练的远距离实例关系外推。

4.6 公开数据集低数据实验

公开数据实验用于验证：

在受控低数据条件下，实例关系监督是否提高B-rep语义分割的数据效率。

建议设置：

（1）1%训练集；
（2）5%训练集；
（3）10%训练集；
（4）100%训练集作为参考。

验证集和测试集必须保持官方完整划分，不能随训练集一起缩小。

建议实验组：

A. Baseline
B. Oracle GT Bias，仅作为不可部署的理论上限
C. Dynamic Bias，无实例损失
D. Dynamic Bias，有实例损失
E. Dynamic Bias，有实例损失并加入困难负样本

最好使用具有真实实例标签的MFInstSeg或MFTRCAD。CADSynth目前只有逐面语义标签，无法完成严格的真实实例监督实验。如果根据训练集语义标签和连通分量构造实例，只能称为“伪实例监督”，并必须说明其局限。

公开数据阶段建议使用多个随机子集或多个随机种子，报告平均值和标准差。论文中宜使用“低数据训练”或“数据高效学习”，不宜直接称为严格的few-shot learning。

4.7 消融实验与结果分析

建议分析：

（1）Baseline与SPE-PCAAG；
（2）Dynamic Bias无实例损失与有实例损失；
（3）普通负样本与困难负样本；
（4）不同实例损失权重；
（5）不同K-hop范围；
（6）不同数据比例下的性能变化；
（7）Oracle与动态偏置之间的差距；
（8）同类不同实例面之间的亲和预测能力。

关键解释逻辑：

Oracle优于Baseline，说明实例关系具有利用价值；
Dynamic加实例损失优于无实例损失，说明网络确实学习到实例结构；
困难负样本继续提升，说明模型改善了同类不同实例混淆；
Oracle提升明显但Dynamic不提升，说明实例关系有价值，但动态预测分支尚未学好；
Oracle也无提升，则说明当前任务中实例偏置的作用可能有限。

本章预期结论：

训练期实例关系监督能够使模型学习隐式实例结构，并在推理阶段不输入实例标签的情况下指导语义分割，尤其有助于低数据条件下的特征区分。


七、第5章 面向大型航空机匣的局部训练—整图推理及UG集成应用

本章定位：

第5章不是简单介绍UG界面，而是解决大型机匣训练显存不足、少量真实模型迁移学习、完整机匣推理和CAD结果回映射等工程问题。

建议章节名称：

《面向大型航空机匣的局部训练—整图推理及UG集成应用》

5.1 大型航空机匣识别问题分析

（1）真实完整机匣数量约20个；
（2）单个机匣可包含上千个面；
（3）完整图训练的注意力复杂度和显存开销较高；
（4）随机局部裁剪会丢失完整机匣位置信息；
（5）合成公开数据和真实机匣之间存在领域差异。

5.2 局部训练—整图推理方法

建议流程：

完整机匣建立B-rep图
→ 在完整图上计算全局柱坐标
→ 仅从训练机匣中采样约200节点的连通子图
→ 局部子图继承完整模型的全局柱坐标
→ 使用局部子图训练
→ 验证和测试阶段输入未见完整机匣
→ 输出完整机匣的逐面语义类别

用户此前在10个机匣上已经证明局部输入训练、完整机匣推理能够运行，可作为可行性预实验。但最终加入SPE-PCAAG和动态实例偏置以后，仍需按照最终网络和规范数据划分重新运行正式实验。

5.3 公开数据预训练与Aero-Casing微调

公开数据权重可以用于机匣训练初始化，但不能替代机匣实验。

建议流程：

公开实例数据集预训练
→ 保留几何编码器、图Transformer和实例亲和分支
→ 替换机匣语义分类头
→ 加入或微调SPE-PCAAG
→ 使用机匣局部子图微调
→ 在完整机匣上测试

建议至少比较：

A. Baseline从零训练
B. Baseline使用公开权重微调
C. SPE-PCAAG与IAAB从零训练
D. SPE-PCAAG与IAAB使用公开权重微调

这样可以区分普通迁移学习收益和新方法本身的收益。

5.4 UG集成系统总体架构

UG端属于在线识别和工程应用系统，与第3章的Qt离线标注工具职责不同。

第3章Qt工具：

原始机匣→自动标注→人工修正→语义/实例标签→训练BIN

第5章UG系统：

待识别机匣→B-rep图提取→调用训练模型→整图预测→结果回写UG

5.5 模型数据提取与识别结果回映射

重点解决：

UG Face ID ↔ Graph Node ID ↔ Network Prediction

应保证每个UG面与图节点之间具有稳定映射，以便将预测类别和实例结果可靠地回写到正确的CAD面。

可实现功能：

（1）一键提取当前UG机匣模型；
（2）自动生成推理输入；
（3）调用训练后的识别网络；
（4）按预测类别给UG面着色；
（5）特征类别筛选和高亮；
（6）特征实例高亮；
（7）类别、数量和面积统计；
（8）识别结果导出；
（9）错误结果人工修正。

5.6 Aero-Casing实验设计

真实机匣必须先按完整父模型划分训练、验证和测试，再从训练机匣生成局部子图。同一个父机匣的局部子图不能同时出现在训练集和测试集。

由于完整机匣数量约20个，建议采用父机匣级5折交叉验证，或至少使用严格的父机匣独立测试集。

测试阶段：

（1）输入完整机匣；
（2）batch_size设为1；
（3）关闭梯度；
（4）不输入语义标签；
（5）不输入实例标签；
（6）动态实例偏置由网络自行生成。

建议消融：

（1）Baseline；
（2）Baseline加SPE-PCAAG；
（3）Baseline加IAAB；
（4）Baseline加SPE-PCAAG和IAAB；
（5）上一组加入困难负样本；
（6）Oracle GT Bias，仅作为上限。

建议报告：

（1）Accuracy；
（2）Macro-F1；
（3）mIoU；
（4）各类别IoU；
（5）完整机匣推理时间；
（6）训练与推理显存；
（7）模型参数量；
（8）局部训练与完整训练的资源对比；
（9）不同机匣上的成功与失败案例；
（10）UG系统运行结果和可视化。

5.7 工业案例分析

选取具有代表性的完整机匣展示：

（1）原始UG模型；
（2）B-rep图与局部采样；
（3）完整机匣语义分割结果；
（4）同类不同实例的识别情况；
（5）典型错误；
（6）UG着色与统计结果；
（7）推理时间和资源消耗。

本章预期结论：

所提方法能够利用局部子图完成训练，并在完整未见机匣上进行整图推理；结合公开数据预训练、SPE-PCAAG和动态实例亲和偏置，可在真实小样本工业场景中完成制造特征识别，并实现UG环境下的结果展示与应用。


八、第6章 总结与展望

6.1 研究工作总结

分别总结：

（1）自动标注和Aero-Casing数据集；
（2）SPE-PCAAG和动态实例亲和偏置；
（3）局部训练—整图推理和UG应用系统。

6.2 主要创新点

建议凝练为：

创新点1：
提出融合几何拓扑规则和属性约束子图同构的航空机匣制造特征自动标注方法，构建包含逐面语义标签与实例标签的Aero-Casing数据集。

创新点2：
提出SPE-PCAAG与动态实例亲和注意力偏置，在训练阶段利用实例关系监督，在推理阶段无需输入实例标签，实现实例结构对语义分割的隐式引导。

创新点3：
提出面向大型航空机匣的局部训练—整图推理方法，并完成UG集成，实现从CAD模型输入到制造特征识别结果回写的工程闭环。

6.3 局限性

（1）真实完整机匣数量仍然有限；
（2）柱坐标依赖统一的轴线、原点和角度基准；
（3）完整图推理仍具有二次注意力复杂度；
（4）自动标注规则和模板对新类型特征仍需扩展；
（5）动态实例亲和关系与Oracle实例关系之间可能仍存在差距。

6.4 未来工作

可包括：

（1）扩大Aero-Casing数据集；
（2）研究更高效的稀疏或分块整图注意力；
（3）联合输出语义类别和显式特征实例；
（4）提升自动标注方法对新特征的泛化能力；
（5）与工艺规划和加工参数推荐进一步集成。


九、三章内容边界

第3章重点是“如何得到高质量训练数据”：

几何拓扑规则、子图同构、自动标注、人工校正、数据集和BIN生成。

第4章重点是“如何在低数据条件下提高识别精度”：

SPE-PCAAG、动态实例偏置、实例关系损失、困难负样本和公开数据实验。

第5章重点是“如何处理大型真实机匣并完成工程落地”：

局部训练、整图推理、迁移微调、完整机匣验证和UG集成。

需要避免：

（1）第3章和第5章都大量介绍软件界面；
（2）第3章只写Qt操作步骤而缺少算法和实验；
（3）第5章只写UG按钮调用而缺少大型机匣方法和性能验证；
（4）把公开数据集实验直接当作机匣有效性的证明；
（5）将训练子图数量当作独立机匣样本数量；
（6）测试时使用真实语义或实例标签构造注意力偏置；
（7）在切分子图后随机划分数据集，造成父机匣泄漏。

十二、总体评价

“自动标注与数据集构建—小样本实例引导网络—大型机匣UG应用”能够构成一篇完整的工程类硕士毕业论文。

三章分别具备：

（1）数据和标注方法方面的研究内容；
（2）网络模型和训练方法方面的算法内容；
（3）大型工业模型处理和CAD集成方面的工程内容。

最终论文是否有说服力，不取决于是否继续增加更多模块，而取决于三项工作能否形成统一的数据闭环，并通过无标签泄漏、父机匣独立划分和可重复实验获得可信结果。
