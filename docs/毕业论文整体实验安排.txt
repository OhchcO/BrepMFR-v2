航空机匣制造特征识别毕业论文整体实验安排
整理日期：2026年7月24日

一、实验总体目标

本论文实验围绕以下五个研究问题展开：

RQ1：几何拓扑规则与子图同构相结合，能否提高航空机匣制造特征的标注效率并保证标签质量？

RQ2：在公开数据集的低数据训练条件下，动态实例亲和注意力偏置能否提高B-rep语义分割性能？

RQ3：实例亲和损失和困难负样本是否能够使模型真正学习同实例聚合、异实例分离的结构关系？

RQ4：公开数据集上学习到的B-rep几何、拓扑和实例关系知识，能否迁移到真实小样本Aero-Casing数据集？

RQ5：在完整机匣训练容易显存溢出的情况下，局部连通子图训练、完整机匣整图推理是否有效，并能否集成到UG环境？

对应四部分实验：

第一部分：Qt自动标注工具及Aero-Casing数据质量实验；
第二部分：MFInstSeg公开数据集低数据实验；
第三部分：Aero-Casing局部训练、整图推理和迁移学习实验；
第四部分：UG集成系统功能、效率和完整案例实验。


二、为什么建议使用MFInstSeg

MFInstSeg适合作为公开数据集上的低数据验证集，主要原因如下：

1. MFInstSeg包含超过6万个合成B-rep CAD模型。
2. 数据集包含24种制造特征及stock背景类别，可按25类完成逐面语义分割。
3. 数据集同时提供逐面语义标签、实例关系标签和底面标签。
4. 其实例标签以N×N稠密关系矩阵表示，可以直接用于构建面与面之间的同实例监督。
5. 官方提供train、val和test划分，可进行公平、可复现的低数据实验。
6. AAGNet已经在该数据集上进行了语义、实例和底面多任务识别，可作为相关工作和对照参考。

AAGNet官方代码：
https://github.com/whjdark/AAGNet

三、MFInstSeg是否需要转换成BIN

结论：

如果继续使用当前BrepMFR的数据加载器和训练代码，MFInstSeg需要转换成与BrepMFR兼容的DGL BIN格式。

原因是：

1. MFInstSeg官方数据通常组织为steps、aag、labels等目录。
2. AAGNet读取aag/graphs.json或graphs.pkl，并从labels目录读取语义、实例和底面JSON标签。
3. 当前BrepMFR通过dgl.data.utils.load_graphs读取每个模型对应的.bin文件。
4. 当前BrepMFR除了DGL图，还要求面网格、边网格、面属性、边属性和预计算的图距离张量。
5. 因此，不能只把官方JSON文件改名为.bin，也不能仅保存一个普通DGL邻接图。

当前BrepMFR每个BIN至少需要包含以下信息。

1. DGL图节点数据

ndata["x"]：面UV网格，形状约为[N,U,V,7]；
ndata["y"]：面面积；
ndata["z"]：面类型；
ndata["l"]：面环数量；
ndata["a"]：面邻接或相关离散属性；
ndata["f"]：逐面语义标签。

2. DGL图边数据

edata["x"]：边曲线采样网格，形状约为[E,L,7]；
edata["t"]：边类型；
edata["l"]：边长度；
edata["a"]：边角度；
edata["c"]：边凹凸性或光滑关系。

3. BIN附加张量

edges_path：任意节点对之间最短路径对应的边序列；
spatial_pos：任意节点对之间的拓扑距离；
d2_distance：面与面之间的欧氏空间关系编码；
angle_distance：面与面之间的角度关系编码。

4. 为动态实例偏置新增的监督

建议在每个BIN的附加张量中增加：

inst_y：形状为[N,N]的同实例关系矩阵。

其中：

inst_y[i,j]=1表示面i和面j属于同一个制造特征实例；
inst_y[i,j]=0表示两者属于不同实例。

MFInstSeg官方实例标签本身就是关系矩阵形式，因此可以直接用作动态实例亲和分支的训练目标，不需要先恢复成实例编号。


四、MFInstSeg转BIN的推荐方案

方案A：离线转换成BrepMFR BIN，推荐

使用MFInstSeg的STEP、官方gAAG和JSON标签，生成与CADSynth及Aero-Casing一致的BrepMFR BIN文件。

优点：

1. 可以最大限度复用当前BrepMFR的数据加载、批处理和训练代码。
2. CADSynth、MFInstSeg和Aero-Casing使用统一数据接口。
3. 后续公开预训练与机匣微调更容易复用权重。
4. 实验中只有数据集发生变化，便于保证基线公平。

缺点：

1. 需要编写一次性转换程序。
2. 必须严格验证STEP面顺序和官方标签面索引完全一致。
3. 需要计算BrepMFR专用的spatial_pos、edges_path、d2_distance和angle_distance。

方案B：为BrepMFR新增MFInstSeg原生数据加载器

直接读取AAGNet的graphs.json、labels.json和gAAG属性，并将其转换为BrepMFR训练批次。

优点：

1. 不需要为每个模型生成BIN文件。
2. 可以直接复用官方gAAG和标签组织。

缺点：

1. 需要重写或扩展dataset.py和collator.py。
2. AAGNet与BrepMFR的面属性、边属性和UV网格组织不完全相同。
3. 容易使MFInstSeg实验和原始BrepMFR基线使用不同输入特征，降低公平性。
4. 每次训练都要进行更多在线预处理。

综合考虑，毕业论文阶段优先选择方案A。


五、MFInstSeg转换流程

推荐流程：

MFInstSeg官方模型
→ 读取官方gAAG和STEP
→ 建立DGL面邻接图
→ 提取面UV网格及面属性
→ 提取边曲线网格及边属性
→ 读取seg语义标签
→ 读取inst实例关系矩阵
→ 计算spatial_pos和edges_path
→ 计算d2_distance和angle_distance
→ 写入BrepMFR兼容BIN
→ 生成train.txt、val.txt和test.txt

优先使用官方gAAG中已有的图结构和面索引，避免重新遍历STEP时产生面顺序变化。

如果必须从STEP重新提取面和边，应当进行以下对齐检查：

1. STEP提取的面数量必须等于官方seg标签数量。
2. 实例关系矩阵尺寸必须为N×N。
3. 重新提取的邻接关系必须与官方gAAG一致。
4. 随机选择模型，将语义标签着色显示，确认标签落在正确面上。
5. 检查同一实例关系矩阵与模型上实际制造特征一致。
6. 发现任何面顺序不一致时，不允许直接批量转换。

六、MFInstSeg转换验证实验

不能直接转换全部6万多个模型后再发现格式错误。建议设置四级验证。

第一级：单模型字段验证

选择1个模型，检查：

1. DGL图可以被load_graphs正常读取。
2. 节点数等于官方语义标签长度。
3. inst_y形状为N×N。
4. inst_y对称。
5. inst_y对角线符合预定定义。
6. 所有语义标签在0至24范围内。
7. 节点、边和附加张量形状符合BrepMFR要求。

第二级：10模型批量验证

随机选择10个不同复杂度模型：

1. 全部能够通过BrepMFR Dataset和Collator。
2. batch_size大于1时可以正常拼接。
3. 标签着色结果与官方标签一致。
4. 最短路径、距离矩阵和边序列无越界。

第三级：小样本过拟合验证

选择20至50个模型，只训练Baseline：

1. 训练损失应持续下降。
2. 训练集准确率应显著上升。
3. 如果无法在极小训练集上拟合，优先检查标签、字段和维度，不进行正式实验。

第四级：1个epoch完整数据管线测试

使用1%训练列表：

1. 完整运行一个epoch；
2. 验证集完整推理一次；
3. 检查显存、NaN、标签越界和保存日志；
4. 确认测试集没有参与训练或超参数选择。

以上四级全部通过后，才能批量开展正式实验。


七、MFInstSeg低数据划分

MFInstSeg官方总量约62,495个模型，官方采用约70%训练、15%验证、15%测试的划分。实际样本数量以下载后的官方train.txt、val.txt和test.txt行数为准。

低数据比例只作用于官方训练集：

1%训练集：round(0.01×N_train)，约数百个模型；
5%训练集：round(0.05×N_train)，约两千余个模型；
10%训练集：round(0.10×N_train)，约四千余个模型；
100%训练集：完整官方训练集，可作为参考或预训练使用。

验证集和测试集始终保持官方完整划分。

禁止：

1. 将验证集和测试集也缩小为1%。
2. 从全部数据中重新随机抽取1%后再划分训练和测试。
3. 为了得到更好结果反复抽取子集并选择最优子集。

建议使用3个固定随机种子：

seed=42
seed=3407
seed=2026

每个随机种子生成嵌套训练子集：

1%集合包含于5%集合；
5%集合包含于10%集合；
10%集合包含于完整训练集。

嵌套划分有利于绘制公平的数据效率曲线。

生成子集后，应统计每个子集：

1. 各语义类别的面数量；
2. 各类别出现的模型数量；
3. 各类别实例数量；
4. 同实例正样本数量；
5. 同类不同实例困难负样本数量。

如果某个1%子集缺失重要类别，应重新定义带类别覆盖约束的固定抽样规则，并在所有方法中使用同一子集。


八、公开数据实验假设

H1：

在MFInstSeg的1%、5%和10%训练条件下，Dynamic Bias加实例亲和损失应优于相同条件下的Baseline。

H2：

Dynamic Bias加实例亲和损失应优于Dynamic Bias但不使用实例亲和损失，说明提升来自实例关系监督，而不是单纯增加参数。

H3：

加入同语义、不同实例的困难负样本后，模型在同类不同实例面关系上的判别能力应进一步提高。

H4：

Oracle GT Bias应优于或接近Baseline之上，表明真实实例关系对语义分割存在可利用上限。

H5：

方法在1%条件下的相对提升预计大于100%训练条件，说明实例关系具有低数据正则化作用。

以上是待验证假设，不应在实验完成前写成确定结论。


九、MFInstSeg实验模型组

P0：BrepMFR Baseline

输入：

几何、拓扑和原始位置关系。

损失：

L_semantic

用途：

建立低数据基线。


P1：Oracle GT Instance Bias

输入：

除正常输入外，直接使用真实inst_y构造注意力偏置。

损失：

L_semantic

用途：

测量真实实例关系对语义分割的理论上限。

注意：

该模型在测试阶段使用真实实例标签，只能作为Oracle诊断实验，不能称为最终方法，也不能与可部署方法混为一谈。


P2：Dynamic Bias，无实例亲和损失

输入：

只使用几何、拓扑和网络中间特征。

偏置：

由实例嵌入分支动态预测。

损失：

L_semantic

用途：

判断动态偏置分支能否仅通过语义梯度自发学习有效关系，同时控制新增参数量的影响。


P3：Dynamic Bias，加实例亲和损失

输入：

训练和推理均只输入几何、拓扑和网络特征。

训练监督：

inst_y仅用于计算L_affinity。

损失：

L_total=L_semantic+λ_inst L_affinity

用途：

验证实例关系监督是否能够提高语义分割。


P4：Dynamic Bias，加实例亲和损失和困难负样本

困难负样本：

语义类别相同、实例不同、拓扑距离较近的面关系。

损失：

L_total=L_semantic+λ_inst L_affinity_hard

用途：

验证困难负样本是否改善同类不同实例混淆。


十、MFInstSeg实验执行顺序

阶段A：1%单随机种子预实验

先使用seed=42运行：

1. P0 Baseline
2. P1 Oracle
3. P2 Dynamic Bias无实例损失
4. P3 Dynamic Bias有实例损失
5. P4 Dynamic Bias有实例损失和困难负样本

该阶段用于快速验证整体方向，不立即进行大规模重复实验。

检查点A：

1. 如果Oracle与Baseline几乎没有差异，先检查偏置注入位置和强度，不立即扩大实验。
2. 如果Oracle有明显提升但P3无提升，重点检查实例嵌入、损失权重和正负样本平衡。
3. 如果P2和P3都提升但差异很小，检查网络是否主要通过语义损失学习关系。
4. 如果P4退化，检查困难负样本比例是否过高。


阶段B：1%三随机种子正式实验

在三个固定1%子集上重复P0至P4。

报告：

平均值
标准差
每个随机种子的独立结果

这一阶段完成最核心的公开小样本实验。


阶段C：数据效率曲线

优先对以下三个模型运行1%、5%和10%：

1. P0 Baseline
2. P3 Dynamic Bias加实例损失
3. P4 Dynamic Bias加实例损失和困难负样本

P1 Oracle和P2无实例损失可以主要在1%条件下作为诊断和消融。如果计算资源充足，再扩展到5%和10%。

最终绘制：

横轴：训练数据比例1%、5%、10%；
纵轴：mIoU、Macro-F1或Accuracy；
曲线：Baseline、Dynamic+Instance、Dynamic+Instance+Hard Negative。


阶段D：完整MFInstSeg预训练，可选但推荐

如果时间和计算资源允许：

1. 使用完整官方训练集训练Baseline；
2. 使用完整官方训练集训练最终IAAB模型；
3. 保存通用B-rep骨干和实例亲和分支权重；
4. 用于Aero-Casing迁移微调。

如果完整训练成本过高，也可以先使用10%训练得到的权重进行机匣迁移实验，但论文必须明确预训练数据比例。


十一、MFInstSeg训练公平性控制

同一数据比例和随机种子下，所有模型必须保持：

1. 相同训练、验证和测试列表；
2. 相同随机初始化种子；
3. 相同batch_size；
4. 相同训练epoch；
5. 相同优化器和学习率策略；
6. 相同数据增强；
7. 相同早停规则；
8. 相同模型选择标准；
9. 相同测试代码；
10. 除研究模块外其他超参数尽量一致。

最佳模型只能根据验证集指标选择，例如验证集mIoU。

测试集只在模型和超参数确定后用于最终评价，不能根据测试结果反复调参。

类权重、正负样本比例和困难负样本采样参数，只能根据训练集统计计算。


十二、MFInstSeg评价指标

1. 语义分割指标

Face Accuracy
Macro-F1
mIoU
每类别Precision、Recall、F1和IoU

Accuracy可能被stock或高频类别主导，因此论文主指标建议使用mIoU和Macro-F1。

2. 实例亲和关系指标

Pair Accuracy
AUROC
AUPRC
Affinity F1
同实例正样本召回率
异实例负样本准确率

由于正负面关系通常不平衡，AUPRC比单独Pair Accuracy更有解释力。

3. 困难负样本专项指标

只在“语义相同、实例不同、拓扑距离较近”的面关系集合上统计：

Hard-negative Accuracy
Hard-negative AUPRC
错误高亲和关系比例

4. 资源指标

参数量
训练显存
推理显存
单模型平均推理时间

注意：

当前方法利用实例关系指导语义分割，但不一定显式输出最终实例分组。因此，在未增加聚类或实例输出模块之前，不应声称完成完整实例分割，也不必强行报告PQ等全景分割指标。


十三、动态实例偏置建议实现协议

建议在前半部分Transformer获得初步语义和几何表示后，再预测实例关系，并在后半部分Transformer使用实例偏置。

例如：

第1至4层：
只使用原始几何、拓扑和位置偏置。

中间实例嵌入：
E=Normalize(W_I H)

实例亲和概率：
P_ij=sigmoid((e_i·e_j-δ)/τ)

实例注意力偏置：
B_inst,ij=g(2P_ij-1)

第5至8层：
在原始注意力偏置上加入B_inst。

训练时：

真实inst_y只进入L_affinity，不进入动态偏置预测分支。

推理时：

没有真实inst_y，P_ij和B_inst完全由网络自行生成。

建议仅在K-hop邻域内计算或使用实例关系，初始可测试K=6或K=8。远距离关系不参与实例损失或被掩码，避免局部训练后在完整图上对未经训练的远距离关系进行外推。


十四、实例亲和损失采样

如果对完整N×N关系矩阵全部计算损失，背景面和普通负样本可能占据绝大多数。

建议每个模型采样：

1. 同实例正样本；
2. 不同语义类别普通负样本；
3. 同语义、不同实例困难负样本；
4. 必要时加入拓扑距离约束。

建议初始比例：

正样本：普通负样本：困难负样本 = 1：1：1

该比例仅作为初始实验设置，最终应根据训练集统计和验证集结果确定。

可测试的实例损失权重：

λ_inst ∈ {0.05, 0.1, 0.2, 0.5}

先在1%训练集的固定随机种子上完成超参数选择，再冻结参数用于其他随机种子和数据比例。


十五、Aero-Casing自动标注实验

目标：

评价Qt自动标注工具的准确性、自动覆盖率、人工修正率和效率。

建议选取3至5个代表性机匣，优先选择未参与规则和子图模板设计的模型。

流程：

十六、Aero-Casing数据划分

真实机匣的独立样本单位是完整父机匣，不是从父机匣裁剪出的子图。

必须先划分完整机匣，再生成训练子图。

禁止：

1. 先把所有机匣切成大量子图，再随机划分训练和测试。
2. 同一父机匣的不同子图同时进入训练集和测试集。
3. 将几千个局部子图称为几千个独立真实机匣样本。

如果最终约有20个完整机匣，推荐使用父机匣级5折交叉验证：

每折约16个机匣训练；
约4个机匣测试；
从训练机匣中再划分验证机匣或采用内部验证策略。

每个折中：

训练：约200节点的连通局部子图；
验证：尽量使用完整验证机匣；
测试：使用完整未见机匣；
测试batch_size=1；
关闭梯度；
不输入语义标签；
不输入实例标签。

每个父机匣生成的训练子图数量应尽量平衡，防止某个大型机匣因子图数量过多主导训练。


十七、Aero-Casing空间坐标协议

SPE-PCAAG依赖全局柱坐标，因此必须统一：

1. 机匣中心轴方向；
2. 坐标原点；
3. 轴向正方向；
4. 周向角度零点；
5. 尺寸归一化方式。

建议使用：

r_norm
z_norm
sin(theta)
cos(theta)

柱坐标必须先在完整机匣上计算，再由局部子图继承。不能在每个局部子图内部重新计算中心轴、原点和归一化范围，否则不同子图之间的位置含义不一致。

建议增加坐标消融：

1. 不使用SPE；
2. 使用笛卡尔坐标；
3. 使用r、theta、z；
4. 使用r、sin(theta)、cos(theta)、z；
5. 随机旋转或改变角度零点后的鲁棒性测试。


十八、Aero-Casing实验模型组

为区分方法收益和公开预训练收益，建议设置以下模型。

C0：Baseline，从零训练

证明机匣上的原始低样本性能。

C1：Baseline，MFInstSeg预训练后微调

证明普通公开数据迁移学习的收益。

C2：Baseline加SPE-PCAAG，预训练后微调

证明全局柱坐标对局部训练、整图推理的作用。

C3：Baseline加IAAB，预训练后微调

证明实例亲和偏置在真实机匣上的作用。

C4：Baseline加SPE-PCAAG和IAAB，预训练后微调

验证两个模块是否互补。

C5：C4加困难负样本

作为最终完整方法。

C6：SPE-PCAAG加Oracle GT Bias

只用于测量真实实例关系的上限，不作为最终推理模型。

为了进一步区分预训练和模型结构，建议补充：

C7：SPE-PCAAG和IAAB，从零训练

关键比较：

C1>C0：说明公开预训练有效；
C7>C0：说明新方法在不依赖公开预训练时也有作用；
C4>C1：说明相同预训练条件下新方法优于Baseline；
C5>C4：说明困难负样本具有额外贡献；
C5最好：说明预训练、SPE和IAAB可以互补。


十九、Aero-Casing正式训练与微调流程

第一阶段：公开数据预训练

使用MFInstSeg训练Baseline或IAAB模型。

第二阶段：机匣模型初始化

建议保留：

面UV网格编码器；

建议重新初始化或调整：

机匣语义分类头；
SPE-PCAAG输入层；
与公开类别数量强绑定的模块。

第三阶段：冻结训练

先冻结部分底层几何编码器，训练新的分类头、SPE和IAAB若干epoch。

第四阶段：联合微调

解冻全部网络，以较小学习率联合训练。

可采用分层学习率：

新分类头和SPE：较大学习率；
Transformer和IAAB：中等学习率；
底层几何编码器：较小学习率。

第五阶段：完整机匣验证和测试

输入完整B-rep图，batch_size=1，关闭梯度，并记录显存、时间和逐面预测结果。

二十八、关键实验检查点

Gate 1：数据转换检查

只有当MFInstSeg面数、语义标签、实例矩阵和图结构完全对齐时，才能开始训练。

Gate 2：小样本过拟合检查

如果模型无法在20至50个训练模型上显著降低损失，先检查数据和代码。

Gate 3：Oracle检查

Oracle用于判断实例关系是否存在提升空间。Oracle失败时，应先检查偏置构造、注入位置和数值范围。

Gate 4：动态实例学习检查

P3必须同时检查语义性能和Affinity AUPRC，不能只观察Accuracy。

Gate 5：无标签推理检查

最终Dynamic模型的验证和测试代码不得读取seg、inst或由它们派生的偏置。

Gate 6：父机匣隔离检查

Aero-Casing训练、验证和测试之间不能共享同一完整机匣的任何子图。

Gate 7：整图推理检查

完整机匣测试必须使用未见父机匣、batch_size=1和no_grad，并记录峰值显存。


二十九、必须避免的实验错误

1. 从测试语义标签生成实例ID或注意力偏置。
2. 将Oracle结果写成可部署方法结果。
3. MFInstSeg训练集使用1%，同时把验证集和测试集也缩小到1%。
4. 不固定随机子集，导致不同模型使用不同训练数据。
5. 只跑一次1%实验就宣称具有稳定的小样本能力。
6. 只报告Accuracy，不报告mIoU和Macro-F1。
7. 不报告实例亲和分支本身是否学会实例关系。
8. 将Aero-Casing裁剪子图随机打散后划分训练和测试。
9. 将局部子图数量当成真实机匣样本数量。
10. 在每个局部子图内部重新计算柱坐标。
11. 公开预训练模型与从零训练Baseline直接比较，却不设置预训练Baseline。
12. 根据测试集表现选择超参数。
13. MFInstSeg重新提取STEP后，不验证面索引和官方标签是否对齐。
14. 只展示Qt和UG界面截图，不提供准确率、时间和成功率。

三十一、总体结论

MFInstSeg是当前公开低数据实验的合适选择，因为它同时提供语义标签和真实实例关系标签，能够完整支持Baseline、Oracle、Dynamic Bias、实例亲和损失和困难负样本实验。

在继续使用当前BrepMFR框架的情况下，需要将MFInstSeg转换为BrepMFR兼容的DGL BIN格式。转换的关键不只是文件扩展名，而是统一面与边特征、语义标签、实例关系矩阵以及BrepMFR所需的最短路径和空间关系张量。

整篇论文的实验逻辑应当是：

MFInstSeg低数据实验
→ 证明动态实例亲和偏置在受控低数据条件下有效；

Aero-Casing实验
→ 证明该方法能够迁移到真实少样本航空机匣，并结合SPE-PCAAG解决局部训练的全局位置问题；

UG系统实验
→ 证明所提方法能够处理完整工业机匣并形成实际CAD应用闭环。
