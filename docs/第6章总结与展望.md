# 第6章 总结与展望

## 6.1 研究工作总结

本文围绕航空机匣制造特征识别中面级标注成本高、B-rep 几何与拓扑信息难以充分结合、同类特征实例易混淆，以及识别结果难以直接落到 CAD 面对象等问题，开展了数据构建、识别模型和 NX 应用集成研究。各部分构成由原始零件、面级与实例级数据、模型预测到 CAD 场景内结果展示的技术链路。当前可核验的定量结论主要来自 MFInstSeg 公开数据集的 1% 训练子集；真实航空机匣上的模型性能与系统级统计仍需在第 3、5 章的正式实验完成后填入。

在数据构建方面，本文设计了面向机匣 B-rep 零件的特征类别与标注流程，利用几何拓扑规则和属性约束子图匹配形成候选特征，再通过人工复核与修正生成面级语义、实例关系及图数据。这一流程为小规模真实机匣数据的构建提供了可执行方案。其相对于纯人工标注的覆盖率、错误率与时间收益，需要以独立机匣及人工核验标签开展对照后报告。**【待补第 3 章结果：机匣数量、面数、类别与实例分布、自动标注准确率或覆盖率、人工修正量及标注用时。】**

在模型方法方面，本文以 B-rep 属性邻接图和 Graph Transformer 为基础，将参数化曲面面内编码、完整零件的柱坐标位置与动态实例关系引导纳入面级语义识别。参数化曲面分支按面面积调整采样点数，使用三维最远点采样选择点位，并以第一基本形式建立近似的面内邻域；实例分支从中间面表示预测同实例亲和关系，以辅助损失训练预测器，并通过后层门控注意力偏置反馈到语义编码。模型推理不需要真实实例标签。输入表征和实例偏置由独立开关控制，使其贡献能够通过配对消融分别评价。

在 MFInstSeg 的 1% 训练数据、种子 42 和完整测试集上，最终配置 `spe_instance` 的 mIoU 为 86.979%，Macro-F1 为 92.584%。与相同输入且具有亲和监督、但不注入偏置的 `spe_affinity_only` 相比，其 mIoU 高 1.554 个百分点；与原始 UV+AAG 基线相比高 3.300 个百分点。原始面间关系的 Pairwise F1 为 86.015%，经预测语义与拓扑邻接约束分组后，Pairwise F1 为 93.064%。这些结果支持该单一种子下实例偏置反馈的增量作用。另一方面，参数化曲面与柱坐标同时启用但不加实例分支的 `spe_pcaag` 比单独参数化曲面配置低 3.515 个百分点，最终配置相对于 `pc_aag` 仅高 0.068 个百分点。因此，输入分支的互补性和最终方法的稳定优势仍须由多种子、不同训练比例及真实机匣实验检验。

在工程实现方面，本文完成了 Siemens NX 2212 C++ 插件与独立 Python 推理程序的连接。插件从当前单实体 STEP 对应的 Work Part 发起识别，使用几何、拓扑签名及全局一一指派建立 OCC/AAG 面与 NX Face Tag 的映射，并在验证完整对应后按实例着色、浏览和高亮。当前可回读的样例输出包含 41 个面、9 个预测实例和可用于映射的 JSON 1.1 面签名；NX 界面内的映射覆盖、回写耗时和真实机匣案例仍需附上运行日志与图像证据。**【待补第 5 章结果：真实机匣整图语义与实例指标、预训练迁移对照、NX 面映射覆盖率、正确回写率及各阶段耗时。】**

## 6.2 主要创新点

第一，针对真实机匣面级语义和实例标签获取困难的问题，本文将几何拓扑规则、属性约束子图匹配与人工复核串联为数据构建流程，并使标注结果能够导出为 B-rep 图学习所需的数据。该工作的核心是把机匣制造特征的几何条件与局部拓扑约束转化为可复用的候选识别与校正过程。**【贡献强度待核：在第 3 章独立对照完成后，据实说明相对人工、单纯规则或单纯子图匹配的增益；当前不写“显著降低成本”等未经测量的结论。】**

第二，本文针对面内几何、零件内结构位置与面间实例关系分别建立可控制的表示与推理分支。参数化曲面编码把面内采样、法向、曲率和局部曲面度量纳入初始面表示；柱坐标分支描述面在完整零件中的径向、周向及轴向参照；动态实例关系分支通过亲和预测与后层门控偏置，将实例监督转化为对语义注意力的辅助约束。这一设计将“面是什么类别”和“哪些面可能属于同一实例”关联起来，同时保持推理阶段不使用真实实例标签。现有 1%/seed 42 的配对结果支持偏置注入相对仅有亲和监督的增量，其他分支的独立与组合收益仍以第 4、5 章补充实验为准。

第三，本文实现了识别输出到 NX 面对象的跨内核回写流程。OCC 构图序号和 NX Face Tag 之间不假设天然一致，而是结合面几何签名、全局一一指派及完整邻接图验证形成可检查的映射；在映射或着色失败时停止部分回写并保留诊断。这一系统方法使模型的面级类别与实例结果能够对应到 CAD 图形窗口中的具体面，为交互浏览提供实现基础。其在多种真实机匣上的映射可靠性和处理效率需以系统级测试结果量化。

## 6.3 研究不足与未来展望

现阶段最主要的不足是实验证据尚未覆盖全部研究目标。公开数据上的正式结果仍集中在 1% 训练子集的单一种子，5%、10% 与多种子配对结果不足；现有单次实验中，参数化曲面与柱坐标的直接组合未优于单独参数化曲面，最终配置相对于最强单分支的优势也很小。后续应固定数据划分、模型选择及配置，在相同种子上比较原始基线、单分支、联合输入、仅亲和监督和偏置反馈，并报告均值、离散程度及不同类别的误差。与其他方法的公平比较还需要统一输入信息、评价口径和计算资源记录。

真实航空机匣的适用性需要独立验证。后续应以完整父机匣为单位冻结标签与训练、验证、测试划分，统一轴线和坐标方向，先计算完整模型的位置编码再提取训练子图，避免子图重归一化改变位置含义。在未见完整机匣上，应同时考察语义识别、同类实例区分、显存与推理时间，并用从零训练与公开数据预训练的配对实验区分模型结构收益和迁移收益。**【待补完成状态：若上述实验已在其他目录完成，应以原始日志、划分清单和逐机匣结果替换本段的“后续应”。】**

工程系统目前适用于可追溯到原始 STEP 的未编辑单实体，跨内核面映射要求完整且无歧义。下一步可研究 NX 当前编辑模型的受控 STEP 导出、多实体零件与装配体处理，以及减少独立 Python 进程重复启动的开销。对无法唯一对应的对称面和不同 CAD 内核造成的曲面分割差异，仍需建立更充分的诊断与人工核查机制。系统扩展应继续以面身份正确、错误情况下无部分着色和结果可追溯为前提。

## 作者工作区：理想目标情形与定稿替换条件

> 以下为**实验目标与条件性写作模板，不是已经取得的研究结论**。完成相应实验后，保留符合原始数据的表述，删除本工作区及未实现目标。

1. **数据构建目标**：在独立真实机匣上，规则与子图匹配结合人工复核的流程，相对纯人工或单一自动策略提高可用标注覆盖率，并降低单位模型的修正时间；同时给出未见父机匣上的标签抽检质量。**【待填：机匣数、各方案覆盖率/错误率、人工用时、统计范围。】**
2. **公开数据目标**：在嵌套的 1%、5%、10% 训练子集及至少 3 个种子下，最终配置相对原始 UV+AAG 基线的 mIoU 和 Macro-F1 平均差值均为正，并报告均值、标准差与逐种子差值；若希望证明组合必要，还应相对最强单分支 `pc_aag` 取得可重复的正向差值。**【待填：每比例、每种子、每对照的原始指标；若存在负向或不稳定结果，按实际情况修改结论。】**
3. **机制目标**：在相同几何输入与实例亲和监督下，启用后层实例偏置相对 `spe_affinity_only` 稳定改善语义指标；困难负样本策略改善同类不同实例关系的判断，并使原始亲和及实例分组指标同步受益。**【待填：配对语义差值、困难负样本 Precision/Recall/F1、分组 Pairwise F1 与 ARI。】**
4. **真实机匣目标**：局部训练与完整图推理保持父零件位置一致，在未见机匣上完成可复核的面级及实例级评价；预训练迁移相对从零训练取得正向结果，且模型改动的贡献能从 2×2 对照中分离。**【待填：父机匣划分、逐机匣结果、显存、耗时及迁移对照。】**
5. **UG/NX 应用目标**：对多件独立机匣实现完整面映射、正确实例着色和可交互高亮，并记录成功率、异常零部分着色及冷启动、缓存命中两种情况下的阶段耗时。**【待填：现场截图、运行日志、面映射与着色核验记录、处理时间。】**
