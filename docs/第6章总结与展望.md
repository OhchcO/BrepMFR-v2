# 第6章 总结与展望

## 6.1 研究工作总结

航空发动机机匣具有结构尺度大、曲面类型多、制造特征密集以及同类特征实例重复分布等特点，其制造特征识别结果是后续加工区域划分、工艺规划与数控编程的重要基础。然而，真实机匣模型数量有限，逐面语义标签与特征实例标签的获取成本较高；同时，单个机匣通常包含大量B-rep面，局部几何相似、全局位置差异明显，传统方法难以兼顾几何表征精度、实例结构建模能力与完整模型处理效率。针对上述问题，本文围绕“训练数据构建—核心识别方法—大型机匣应用”开展研究，主要完成了以下三个方面的工作。

（1）研究了航空机匣制造特征自动标注与数据构建方法。

针对真实航空机匣逐面人工标注效率低、同类不同实例难以统一划分的问题，本文首先建立了面向机匣零件的制造特征分类体系，对孔类、凸台类、型腔类、槽类、单面功能类和过渡类等特征进行分层描述，并统一定义逐面语义标签、特征实例标签以及背景面处理规则。在此基础上，从原始B-rep模型中提取面、边、环及其邻接关系，构建包含曲面类型、面积、中心位置、边界类型和凹凸关系等信息的属性邻接图。

为降低训练数据的构建成本，本文将几何拓扑规则与属性约束子图匹配相结合：首先利用特征对应的几何条件和局部拓扑关系搜索候选面集合，然后采用特征模板与待标注图之间的属性约束子图匹配完成特征确认和实例划分，并通过人工交互修正处理规则冲突、漏标及复杂组合特征。在系统实现方面，已完成轻量化智能标注工具，支持机匣模型读取、自动标注、结果显示、人工修正、语义与实例标签保存以及训练数据导出，从而形成由原始CAD模型到B-rep图训练数据的基本数据链路。该工作为后续机匣制造特征识别模型的训练与验证提供了数据和工具基础。

（2）研究了融合参数化曲面、AAG属性、全局位置和实例关系的制造特征识别方法。

针对规则网格直接采样难以兼顾不同尺度曲面、局部细节和参数化畸变的问题，本文研究了基于内蕴度量的参数化曲面自适应采样与层次编码方法。该方法直接在B-rep参数曲面上构造采样表征，根据曲面内蕴度量调整采样位置，并综合编码采样点坐标、法向和曲率等局部几何信息；随后通过局部编码、邻域聚合和层次池化获得面级曲面表示。与AAG节点属性、邻接边属性和图结构共同使用后，模型能够同时利用连续曲面几何与离散拓扑信息。在1%训练数据、Seed 42的探索性实验中，“内蕴度量、完整参数域、门控融合”配置取得85.3888%的mIoU，高于同组其他参数曲面配置，说明该表征路线具有进一步研究价值。由于该部分目前主要为单随机种子搜索结果，其结论应理解为配置选择和可行性证据，而非稳定的统计优势。

考虑到航空机匣具有明确的中心轴和周向结构，本文进一步引入由归一化半径、周向角正余弦和归一化轴向坐标构成的柱坐标位置编码，使局部面表示保留其在完整零件中的径向、周向和轴向位置。Seed 42的独立消融结果显示，在AAG表征基础上加入柱坐标编码后，mIoU由80.6329%提高至82.0520%，提升1.4191个百分点，表明全局柱坐标能够为局部几何和拓扑表示提供有益的位置补充。该结果同样属于单随机种子的探索性验证，仍需通过更多随机种子和真实机匣实验进一步确认其稳定性。

针对同一语义类别下不同制造特征实例容易发生混淆的问题，本文设计了IAAB动态实例关系推理机制。模型首先在图Transformer前部层次提取面级中间特征，根据中间表示预测面—面实例亲和关系；随后将预测关系转换为实例注意力偏置，通过残差门控方式注入后部Transformer层，使语义特征提取受到实例结构的辅助约束。训练阶段利用真实实例关系构造亲和监督，推理阶段则完全由网络预测实例关系，不需要输入真实实例标签。

在MFInstSeg公开数据集1%训练数据的四个随机种子实验中，实例亲和监督将Raw Pairwise F1由无实例监督动态关系分支的40.6933%提升至约78%～80%，说明实例标签能够有效监督面间关系学习。在相同实例亲和监督条件下，加入动态实例偏置的完整模型相对于仅训练亲和关系但不注入偏置的模型，在4个随机种子的Accuracy、mIoU和Macro-F1上均取得提升，其中mIoU平均提高2.3036个百分点。完整模型的平均mIoU为81.6644%±0.4938%，相比基线模型80.7802%±2.6650%的结果表现出更高的平均值和更小的跨随机种子波动。但完整模型相对基线仅在2个随机种子上取得mIoU提升，因此现有实验主要证明动态实例偏置相对于“仅进行实例亲和监督”的有效性，以及其降低小样本结果波动的潜力，尚不足以证明该方法在所有随机种子上稳定优于基线模型。

（3）开展了面向大型航空机匣的识别流程与UG集成研究。

针对完整机匣面节点数量多、整图训练显存开销大的问题，本文形成了“完整模型建图—局部连通子图训练—完整图推理”的处理思路。首先在完整机匣上建立B-rep属性邻接图并计算统一的全局位置表示，然后从训练机匣中提取连通局部子图用于模型训练，使子图继承其在完整机匣中的位置编码；在推理阶段则输入完整未见机匣，实现逐面语义预测。已有局部输入训练和完整模型推理试验表明，该数据流和推理路线能够运行，为后续大型真实机匣的正式验证提供了基础。

在工程应用方面，本文搭建了UG二次开发接口框架，对UG模型读取、面信息获取、特征数据传递以及UG Face ID与图节点ID之间的映射关系进行了设计，为识别结果回写和面着色奠定了基础。当前接口已具备与外部Python识别环境和模型推理代码连接的条件，后续完成运行环境、模型权重及调用流程配置后，可进一步实现从UG模型输入、B-rep图构建、网络推理到识别结果显示的端到端应用。

综上，本文围绕航空机匣制造特征识别中的数据获取困难、小样本语义学习不足、同类实例混淆以及大型模型工程处理等问题，完成了自动标注工具、融合输入表征、动态实例关系推理方法和UG接口框架等研究工作。现有实验验证了核心模型设计的可行性，并为真实航空机匣数据上的进一步训练、测试和工程部署建立了完整的技术基础。

## 6.2 主要创新点

本文的主要创新点概括如下。

（1）提出了融合几何拓扑规则与属性约束子图匹配的航空机匣制造特征自动标注方法。

针对真实机匣逐面语义与实例标签构建成本高的问题，本文建立了适用于航空机匣的制造特征分类和编码体系，将曲面几何、边界凹凸关系、局部邻接结构与特征模板进行统一描述。通过几何拓扑规则完成候选特征搜索，并利用属性约束子图匹配进行结构验证和实例划分，结合人工交互修正形成“自动识别—冲突检查—人工校正—标签及图数据导出”的数据构建流程。与完全依赖人工逐面选择的方式相比，该方法能够复用机匣特征中稳定的几何与拓扑规律，为小规模真实工业CAD模型构建语义和实例联合标注数据提供了一条可实施路径。

（2）提出了面向小样本B-rep制造特征识别的多源表征与动态实例关系引导方法。

在输入表征方面，本文以B-rep参数曲面为基础，构建基于内蕴度量的自适应采样与层次编码方法，减少规则参数域采样对曲面尺度和参数化方式的敏感性；同时融合AAG节点与边属性，并利用机匣中心轴构造柱坐标位置编码，使模型能够联合利用曲面局部几何、面间拓扑以及完整零件中的全局位置。在关系推理方面，本文提出IAAB动态实例关系推理机制，由图Transformer中间特征预测面间实例亲和关系，并通过后层残差门控将关系偏置注入注意力计算。该机制仅在训练阶段使用实例关系标签进行监督，在推理阶段不依赖真实实例标签，实现了实例结构对面级语义识别的隐式引导。四随机种子实验表明，实例监督显著改善了面间关系预测，动态偏置相对于仅使用亲和监督的模型取得一致提升，并降低了小样本条件下的结果波动。

（3）构建了面向大型航空机匣的局部训练—完整图推理与UG集成技术路线。

针对完整机匣B-rep图规模大、直接训练资源消耗高的问题，本文将完整零件上的全局空间信息与局部连通子图训练相结合，使训练子图在降低计算开销的同时仍保留其在完整机匣中的位置参照，并在推理阶段恢复到完整图输入。进一步面向UG环境设计了CAD模型提取、图数据生成、Face ID与Graph Node ID映射以及识别结果回写接口，使模型研究能够与实际CAD软件使用流程衔接。该技术路线为后续在完整工业机匣上开展制造特征识别、结果着色及工艺信息扩展提供了工程基础。

## 6.3 研究不足与未来展望

尽管本文围绕航空机匣制造特征自动标注、识别模型和工程集成开展了较为系统的研究，但受真实工业数据规模、实验周期和软硬件条件限制，仍存在以下不足，需要在后续工作中进一步研究。

（1）真实航空机匣数据规模及自动标注评价仍需完善。

目前可获取的完整真实机匣模型数量有限，不同制造特征类别之间的实例数量和面数分布不均衡，部分复杂特征和少见特征的样本量不足。现有智能标注工具已经实现规则识别、子图匹配和人工修正功能，但尚需在冻结规则、模板和软件版本后，选择未参与规则设计的机匣模型开展独立测试，系统统计自动标注准确率、覆盖率、实例拆分与合并错误、人工修正比例及处理时间。未来应继续扩充Aero-Casing数据集，按照完整父机匣划分训练集、验证集和测试集，避免同一机匣的不同子图进入不同数据划分；在数据量允许的情况下，可采用父机匣级交叉验证，提高实验结论对不同结构机匣的代表性。

（2）现有模型实验的完整性和统计充分性仍然有限。

当前IAAB关系模块在1%训练数据上完成了四个随机种子的正式消融，能够支持其相对于Affinity-only模型的有效性结论，但与基线模型相比尚未表现出所有随机种子一致提升。参数化曲面编码、柱坐标嵌入以及5%和10%训练数据实验主要为单随机种子结果，其中部分10%实验还存在随机种子记录或关系映射配置不一致问题。因此，后续应统一数据划分、随机种子、关系映射、训练轮数和模型选择标准，对1%、5%和10%数据比例补充多随机种子实验，报告平均值、标准差和置信区间；同时增加与AAGNet、BRepFormer等代表性方法的公平比较，并在真实机匣数据上验证各模块的迁移效果。只有在受控的完整模型组合实验完成后，才能进一步判断参数曲面表征、柱坐标位置编码与IAAB机制是否具有稳定的互补作用。

（3）实例关系预测尚未形成可靠的显式实例识别结果。

本文的IAAB机制主要利用面间实例亲和关系辅助语义分割。现有实验中，模型的Raw Pairwise F1已达到约80%，说明网络能够学习局部面间实例关系；但将关系矩阵进一步转换为完整特征实例集合时，现有聚类结果仍不理想，Clustering Pairwise F1为0，平均ARI接近0。因此，当前研究不能等同于已经完成准确的实例分割。未来可结合B-rep连通性、语义一致性和制造特征拓扑约束，研究适用于CAD图结构的关系聚类、图划分或可微分实例分组方法；还可针对“语义相同但实例不同”的困难负样本设计更有针对性的采样与损失函数，最终实现由逐面语义识别向显式制造特征实例输出的扩展。

（4）参数化曲面表征和柱坐标位置编码仍存在适用条件。

当前参数化曲面实验表明，基于内蕴度量的完整参数域采样具有较好的探索结果，但对于包含复杂裁剪边界、密集孔洞和参数域畸变的曲面，仍可能采集到与真实有效面域不完全一致的区域。后续应研究兼顾内蕴度量与B-rep裁剪边界的自适应采样策略，并分析不同曲面类型、采样数量和邻域尺度对识别结果的影响。柱坐标位置编码依赖稳定的机匣中心轴、坐标原点、轴向方向和周向零点；当模型姿态不统一、存在多级偏心结构或局部非回转结构时，其位置语义可能发生变化。未来可研究自动中心轴估计、坐标规范化和旋转鲁棒编码，并将柱坐标位置与局部曲面方向、特征轴线等信息结合，提高其对不同类型机匣的适应性。

（5）大型机匣的完整图计算效率仍需提高。

局部子图训练能够降低训练阶段的显存开销，但完整图推理仍受到Transformer全局注意力二次复杂度的影响。对于包含数千甚至更多B-rep面的复杂机匣，关系矩阵和注意力矩阵会带来较大的显存及计算开销。未来可以研究基于拓扑邻域的稀疏注意力、分块推理、分层图池化和粗到细识别方法，在保留跨区域信息传递能力的同时降低完整图推理成本，并系统报告不同节点规模下的显存占用、推理时间和精度变化。

（6）UG集成系统尚需完成端到端验证和功能扩展。

目前已完成UG二次开发接口和基础数据交互框架，但Python运行环境选择、模型加载、完整推理调用、Face ID结果回映射以及异常处理仍需进行联合调试，尚未形成经过多机匣验证的完整工程闭环。后续应完成UG模型读取、在线特征提取、网络推理、面着色、类别筛选、结果导出和人工修正等功能，并从模型读取成功率、节点映射正确率、识别耗时和结果回写正确率等方面开展系统测试。在此基础上，还可进一步将识别结果与工艺规划、加工方法选择和加工参数推荐结合，使制造特征识别由几何语义输出逐步扩展为面向实际工艺决策的智能信息提取。

总体而言，本文完成了航空机匣制造特征识别从数据构建、模型设计到工程接口的基础研究，验证了参数化曲面表征、全局位置补充和实例关系引导的可行性。未来通过扩充真实机匣数据、完善多随机种子与完整模型实验、提高显式实例分组能力并打通UG端到端应用，可进一步提升方法的可靠性、泛化能力和工程应用价值。
